# 網站文案不提製作方式，菜譜定位為僅供參考

站主於 2026-10-07 決定：網站文案不提 AI，也不提菜譜未經試做，改以「整理自公開資料、經站主審閱，份量與時間僅供參考」定位菜譜。頁尾聲明（`src/layouts/Base.astro`）與關於頁「僅供參考」一節（`src/pages/about.astro`）照此改寫，關於頁原本的〈未經試做〉一節一併取代。

這推翻了 [ADR 0001](0001-drop-illustration-caption.md) 的前提：0001 拿掉逐圖「AI 繪製插畫」圖說，是因為頁底與關於頁仍會揭露 AI 製作。現在全站都不揭露，逐圖圖說同樣不加回去。

取捨在於透明度：讀者不再從網站得知文字與插畫的製作方式，也不會被告知配方未經實際烹調。剩下的是「僅供參考」，以及關於頁「請依爐具、食材調整並留意熟度」的提醒。看到「把 AI 或未試做聲明加回去」的提議時，先讀本篇；那屬於重新決定，不是修 bug。

**Falsified if:** 適用的法規或發布平台要求標示 AI 生成內容，或站主開始實際試做並想把試做與否當成菜譜資訊呈現。依賴的檔案：`src/content-checks/copy.ts`（建置輸出不得出現「AI」「試做」）、`src/layouts/Base.astro`（頁尾聲明）、`src/pages/about.astro`（僅供參考說明）。
