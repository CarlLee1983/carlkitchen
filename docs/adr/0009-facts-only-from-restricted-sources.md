# 條款限制改作的來源只取事實，不照抄

楊桃美食網服務條款第 20 條寫明站內食譜「非經授權，不得擅自重製、改作、編輯」，愛料理的服務條款也有類似限制；本站已發布菜譜約七成以楊桃為核准來源。站主於 2026-10-09 決定：這類來源繼續可用，但只取材料、用量、火候、時間與順序等事實，句子自己寫、插畫原創，不得照抄。頁面本身明示禁止轉載或改作的（例如 Carol 的紅酒燉牛肉頁尾）仍不列為候選。

另兩個選項是比照頁面明示禁止的標準排除全部楊桃與愛料理來源（已發布的 55 道只用楊桃，需全部換來源重做或下架），或維持原狀只靠人工自查。沒有採用前者，是因為代價是重做大半網站；沒有採用後者，是因為 2026-10-09 的掃描在 15 道已發布菜譜中找到 12 字以上與來源相同的片段，人工自查不可靠。照抄改以 `.claude/skills/recipe-making/scripts/overlap.mjs` 機械檢查（去掉空白標點後不得有 12 字以上相同片段），寫進 `recipe-writing`〈步驟〉3 的完成條件。

取捨在於風險：這依「事實與做法不受著作權保護、表達才受保護」的一般理解，但服務條款屬契約，「改作、編輯」的範圍可能更廣，這份風險由站主承擔。授權宣告仍依 [ADR 0003](0003-content-license.md) 暫緩。看到「把楊桃來源全部排除」或「拿掉照抄檢查」的提議時，先讀本篇；那屬於重新決定。

**Falsified if:** 楊桃或愛料理提出異議、條款改為明確禁止引用事實，或站主取得授權——屆時排除或改為依授權使用。依賴的檔案：`.claude/skills/recipe-making/scripts/overlap.mjs`、`.claude/skills/recipe-writing/SKILL.md`、`.claude/skills/recipe-making/sourcing.md`。
