# 主食是第三種分類，不是標記

站主將大量新增炒麵、炒飯、義大利麵、湯麵等菜色（2026-10-07 規劃，見 [菜譜瀏覽規格](../../.scratch/recipe-browsing/issues/01-browsing-spec.md)）。主食因此成為菜譜分類的第三個值，與非湯料理、湯互斥，而不是和蔬菜菜、蛋白質菜並列的 `staple` 布林標記。詞彙定義見 `GLOSSARY.md`「主食」。

否決標記方案的理由有兩點。第一，標記之間可以疊加，「牛肉炒麵」可能同時被標成主食和蛋白質菜，這樣它就會被配一桌當成配飯的菜。用分類表達，互斥性是天生的，不需要另外寫規則禁止。第二，配一桌引擎以分類分配菜位與湯位，主食是不同的上桌角色（單吃即可成一餐），應該在同一個維度上被排除，而不是在菜位裡再多一條例外。

看到「加一個 `staple: true` 比改分類簡單」的提議時，先讀本篇。

**Falsified if:** 出現一道站主認為必須同時算主食又算配飯的菜（例如要它既出現在「主食」篩選，也能被抽進四菜一湯的菜位），使三種分類無法互斥。依賴的檔案：`src/content/recipe-schema.ts`（分類列舉與「主食不可為配菜候選」規則）、`src/meal-planner/candidates.ts`（候選池依分類分配菜位與湯位）。
