# 上線驗收檢核表

候選池首次達到上線門檻（非湯料理 12 道、湯 3 道）的那個 PR 就是上線 PR。站主把本檢核表貼進該 PR 描述，逐項勾選後才合入；有未通過的項目，修正後再上線。標準來源：`.scratch/recipe-mvp/issues/08-mvp-acceptance.md`。

## 自動檢查（PR 的 CI 必須全綠）

- [ ] CI 的 `verify` 通過（格式、型別、建置、內容與輸出檢查、單元測試、Playwright、`wrangler deploy --dry-run`）
- [ ] 本地對正式內容執行 `pnpm build && pnpm check:content --launch` 通過（候選池非湯料理 ≥ 12、湯 ≥ 3）

## 頁面與內容

- [ ] 五個頁面都可用：首頁、菜譜頁、四菜一湯／五菜一湯頁、關於頁、404
- [ ] 首頁搜尋與分類可用，網址 `/?q=番茄&kind=soup` 開啟後還原搜尋字詞與「湯」分類
- [ ] 頁尾有「菜譜整理自公開資料、經站主審閱，份量與時間僅供參考」；料理圖旁沒有圖說；全站文案不提 AI 或試做（`pnpm check:content` 把關，見 ADR 0004）
- [ ] 關於頁說明內容來源與審閱流程，不列來源連結
- [ ] 菜譜頁列印預覽：隱藏導覽與裝飾，保留材料、做法與成品圖
- [ ] 每份菜譜已由站主逐篇審閱
- [ ] 首頁本期專題依台北日期與指定順位切換；無當期專題回到常青備選，無備選則隱藏，停用 JavaScript 時仍能開啟常青文章
- [ ] 菜譜頁的相關專題只列已發布且確實關聯的文章，最多三篇，日期由新到舊，無關聯時省略整區

- [ ] 手機由導覽列進入「四菜一湯」，搜尋區不重複入口；較寬畫面保留搜尋區入口
- [ ] 配菜頁於 320、390、768、1280 px：搜尋與指定欄位至少 200 px 寬、44 px 高；標籤維持單行、菜名可完整閱讀，縮圖保持 3:2 比例；空白自選與無搜尋結果時仍無水平捲動
