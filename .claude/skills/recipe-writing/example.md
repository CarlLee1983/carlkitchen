# 範例：番茄炒蛋

依 [SKILL.md](SKILL.md) 寫成的完整菜譜文字。內容是示意，未試做；用來對照語氣、欄位與熟度訊號的寫法，不是可發布的菜譜。

## 標題

番茄炒蛋

## 摘要

蛋先炒到半熟盛起，再把番茄炒出汁，最後合在一起。蛋保持柔軟，番茄帶點湯汁，適合配飯。

## 份數與分類

2 人份；非湯料理

## 材料

| 名稱 | 用量             | 備註           |
| ---- | ---------------- | -------------- |
| 番茄 | 2 顆（約 300 g） |                |
| 雞蛋 | 3 顆             |                |
| 青蔥 | 1 支             | 蔥白、蔥綠分開 |

調味

| 名稱   | 用量  |
| ------ | ----- |
| 食用油 | 30 ml |
| 糖     | 5 g   |
| 鹽     | 適量  |
| 水     | 50 ml |

## 做法

1. 番茄去蒂切成小塊；青蔥切段，蔥白和蔥綠分開放。
2. 雞蛋打入碗中，加一小撮鹽打散。
3. 熱鍋後倒入食用油，油熱倒入蛋液。蛋液邊緣凝固後輕推，約七分熟就盛起。
4. 原鍋放入蔥白炒香，下番茄翻炒到軟化出汁，加糖、鹽和水煮一分鐘。
5. 倒回炒蛋拌勻，讓蛋吸一點湯汁，撒上蔥綠就起鍋。

## 小提醒

番茄偏酸時可多加一點糖；想要湯汁多一些，水可加到 80 ml。
