# 菜譜寫作

把站主核准的公開來源**重述**成一份繁體中文、臺灣用語的結構化菜譜。重述是取用來源中的事實（材料、用量、火候、時間、順序），再用自己的句子寫出來；來源的句子、段落結構與圖片都不帶進菜譜。

菜譜必備欄位與草稿／發布邊界以[內容契約](../../../.scratch/recipe-mvp/issues/02-recipe-content-contract.md)為準，來源與審核流程以[本地 AI 製作流程](../../../.scratch/recipe-mvp/issues/03-local-ai-review-workflow.md)為準；本 skill 只管文字怎麼寫。完整範例見 [example.md](example.md)。

## 步驟

1. **確認來源**：只用站主核准的來源網址，把實際採用的網址記入該菜譜的內部來源紀錄（`content/sources/<菜譜識別值>.yaml`，格式 `urls: [網址…]`）。完成條件：每個用到的事實都能指回某個已記錄的核准來源。來源缺必要份量或關鍵步驟時，保留草稿並向站主回報缺口。
2. **抽出事實**：列出材料與用量、每一步的動作、火候、時間及來源提供的熟度訊號。多個來源衝突時，選一種做法並在回報中說明取捨。完成條件：做法中的每個動作與狀態都有來源依據，沒有自行補上的份量或時間（`timeMinutes` 的推估例外，見〈份數、時間與材料〉）。
3. **重述並填寫欄位**：依下方〈寫法〉寫標題、摘要、份數、分類、材料、做法、小提醒與每張圖的替代文字。
4. **提議標記**：提出分類（非湯料理／主食／湯）、是否為配菜候選、蔬菜菜／蛋白質菜，各附一句理由。分類依詞彙表：單吃即可成一餐的炒飯、炒麵、義大利麵與湯麵是主食（湯麵歸主食，不歸湯）；主食不提議配菜候選與蔬菜菜／蛋白質菜標記。這些是提議，由站主審稿時決定。
5. **逐項自查**：〈自查清單〉每一項都成立才送審；不成立就回到對應步驟修正。

## 寫法

### 語氣

平實、友善、像寫給會下廚的朋友。句子短，一句一件事。形容只用來描述口感與狀態（滑嫩、帶湯汁、軟爛），不用宣傳詞。

內容一律是「整理」而非「實作」：用「這道菜」「做法」當主詞，不寫第一人稱的試做經驗、保證成功或口味評價。

### 標題

用臺灣最常見的菜名，例如「番茄炒蛋」「香菇雞湯」。只寫菜名，不加形容詞或噱頭。

### 摘要

一到兩句、約 50 字內：這是什麼菜、口感或特色、適合什麼時候吃。

### 份數、時間與材料

- 份數寫正整數人份。
- `timeMinutes` 必填，是從開始備料到上桌的總分鐘數，含吐沙、醃漬、泡發、燉煮等等待時間。核准來源標示的總時間涵蓋同樣範圍時照用；來源沒寫，或標示的時間明顯沒算進等待（例如短於步驟裡的燉煮時間），就依步驟推估：步驟寫明的時間加上合理的備料與操作時間，可同時進行的不重複計算，四捨五入到 5 分鐘。
- 材料寫名稱與用量。主要材料用公制（g、ml），數字與單位之間空一格，例如 `300 g`、`30 ml`；雞蛋、大蒜、青蔥等可用顆、瓣、支，必要時附公制，例如「2 顆（約 300 g）」。茶匙、湯匙只在公制之外補充。
- 「適量」只用於調味料。
- 需要分開處理的材料加備註，例如青蔥「蔥白、蔥綠分開」。
- 主料在前，調味料另成「調味」一組。

### 做法

- 每步以動作開頭，依實際順序，一步一組連續動作，約 60 字內。
- 來源有依據時，寫出讀者判斷「可以進下一步了」的**熟度訊號**：看得到、聽得到或可計時的狀態，例如「蛋液邊緣凝固」「炒到軟化出汁」「煮一分鐘」。缺少必要訊號時標為待補，不用推測補成已知事實。
- 材料名稱與材料清單完全一致。
- 一步最關鍵的提醒可以強調一處，例如「約七分熟就盛起」。

### 小提醒

一到兩句，只放能改變結果的調整，例如酸度、湯汁多寡、替代材料。沒有就省略。

### 圖片替代文字

描述畫面裡實際畫了什麼，讓看不到圖的讀者知道內容：材料圖寫出可辨識的品項與數量；步驟圖寫出畫中可見的操作或狀態；成品圖寫出主要食物與擺盤。成品圖不畫餐具，替代文字也不提餐具；插畫風格不必寫入。

### 用詞

使用臺灣用語：

| 用     | 對應的他地說法 |
| ------ | -------------- |
| 番茄   | 西紅柿         |
| 馬鈴薯 | 土豆           |
| 高麗菜 | 洋白菜、包菜   |
| 花椰菜 | 菜花           |
| 地瓜   | 紅薯           |
| 鳳梨   | 菠蘿           |
| 鮪魚   | 金槍魚         |
| 起司   | 芝士、奶酪     |
| 奶油   | 黃油           |
| 優格   | 酸奶           |
| 太白粉 | 生粉、淀粉     |
| 不沾鍋 | 不粘鍋         |

同一份菜譜裡，同一樣東西只用一個名稱。

## 自查清單

- [ ] 每個事實都能指回核准來源，且來源已記入內部紀錄
- [ ] 沒有任何句子與來源原文相同或只換幾個字
- [ ] 標題、摘要、正整數份數、烹調時間、分類、至少一項材料、至少一步做法都已填寫
- [ ] `timeMinutes` 含等待時間，並在回報註明是來源標示或依步驟推估
- [ ] 用量使用公制或顆、瓣、支；「適量」只出現在調味料
- [ ] 每步以動作開頭；熟度訊號有來源依據，必要訊號缺漏已標為待補；材料名稱和清單一致
- [ ] 全文沒有試做、實測、保證或第一人稱的口味經驗
- [ ] 全文是臺灣用語與繁體中文
- [ ] 每張圖都有替代文字，且內容和圖、和材料清單一致
- [ ] 分類與標記提議各附理由
