# 去 AI 味

文字寫完、送審前，把機器腔調改回平實的整理文字。**只改腔調**：事實、立場、臺灣用語、數值原樣保留。站主看到的稿子不必逐句再修腔調。

專題、菜譜、食材條目共用這一步；各自的欄位與結構以 [topic-writing](../topic-writing/SKILL.md)、[recipe-writing](../recipe-writing/SKILL.md)、[ingredient-writing](../ingredient-writing/SKILL.md) 為準，本 skill 不改欄位內容的取捨。

## 步驟

1. **標出保護段**：逐項圈出不可動的內容並記下。完成條件：每一項在改完後都能逐字比對回原稿。
   - 數值與單位、材料名稱、時間、火候、熟度訊號、食材與菜名
   - 臺灣用語（見[用詞表](../recipe-writing/SKILL.md)）
   - 來源標示、「待補」「未經試做」「來源未提供」這類揭露與不確定性
   - 原稿的猶豫語氣（「約」「可依口味」）；不把推測改成肯定
2. **先拆結構殼**：只刪或改〈結構殼〉的句子，這一輪不潤詞。判準：刪掉這句，是否損失事實、立場或動作？不損失就是殼，刪掉。
3. **再改句子與語感**：依〈句子與語感〉改寫，短句直述，先講結論再講細節。完成條件：改過的每句仍是原稿已有的事實，沒有新增宣稱。
4. **對照保護段**：把步驟 1 的清單逐項對回改後的稿子。有任何差異，還原。
5. **逐項自查**：〈自查清單〉全部成立才送審。原稿已經乾淨就只做最小修改，並在回報註明「無需大改」。

## 站點限制

改寫時守住這些，違反的句子刪掉或改回有來源的陳述：

- 站上文字是整理，不是實作：不宣稱試作、實測，不保證成功，不寫「我試過」「我家」這類第一人稱經驗。站主自己加的個人心得由站主寫，代理不替站主捏造。
- 食材與料理只寫來源支持的特性，不寫療效、養生、對身體的好處。
- 口感與狀態用中性形容（滑嫩、帶湯汁、軟爛）；促銷語氣（超級下飯、絕對好吃、必學、爆汁、一試就愛上）一律換成可核對的事實。
- 結尾寫到事情講完就停，不加總結、升華或呼應開頭的句子。
- 並列的事實本來就是清單（材料、步驟、欄位）時照原樣；專題等散文不切成「粗體標題＋重述標題」的清單，粗體一段至多一處。
- 缺資料時維持原稿的缺口標示，不用順口的描述填滿。

## 結構殼

禁的是修辭動作，換字照樣算命中。改法固定：找出這句原本想說的事實，用普通句子講出來。

- **翻案腔**：先立一個誤解再推翻。「不是 A 而是 B」「看似 A 實則 B」「重點不在 A 而在 B」。留事實，丟框架。
- **命令式開頭**：「別急著 X，先 Y」「記住一件事」。改成直接陳述做法與原因。
- **宏大背景開頭**：「在快節奏的現代生活中」「料理是一門藝術」。第一句就碰到這道菜或這項原理。
- **空泛收尾與展望**：「總之，掌握 X 就能做出美味料理」、重述全文、「期待你也試試」。刪。
- **聊天殘留**：「希望對你有幫助」「以下是整理」「好問題」。刪。
- **意義尾巴**：事實後面掛「，體現了……」「，展現出……」「是……的關鍵」。刪掉後事實還完整就刪。
- **模糊歸因**：「專家認為」「許多廚師都說」而沒有具名來源。專題要接回該節的核准來源，接不回就刪。

## 句子與語感

- **假洞見標記**：「其實」「真正」「本質上」「關鍵在於」「值得注意的是」。刪掉標記，句子站不住代表那句本來就空。
- **提示性冒號**：「一句話總結：」「重點是：」。冒號留給表格欄位與短標籤。
- **破折號**：不用 `—`、`——`，拆成兩句或改逗號。
- **動詞名詞化**：「進行翻炒的動作」「達到軟嫩的效果」→「翻炒」「煮到軟嫩」。
- **三項以上的同構排比**：讓成品「更香、更嫩、更下飯」。兩項為限，或換成各自的具體狀態。
- **贅語**：「不得不說」「毫無疑問」「綜上所述」「由此可見」，整句刪。
- **借喻與抒情**：用倉庫、鑰匙、靈魂、舞蹈包裝料理原理，或讓抽象名詞做具體動作。比喻只留給解釋機制，且每個部件對得上真實機制。
- **直譯腔**：每個詞都該是臺灣人對朋友講得出口的說法；翻不順的英文概念，寧可用原詞。
- **假具體**：原稿沒有的時間點、氣味、聲音、擺盤或場景。刪，不補。
- **句長有高低差**：每句長度相近、每段都用短判斷收尾，就是節拍器。同一樣東西保持同一個名稱，不輪流換說法。

## 自查清單

- [ ] 數值、單位、材料名稱、菜名、熟度訊號與改前逐字相同
- [ ] 臺灣用語與繁體中文未變，原稿的「未經試做」「待補」「來源未提供」等揭露還在
- [ ] 原稿的猶豫語氣還在，沒有把推測改成肯定
- [ ] 沒有新增原稿沒有的事實、第一人稱經驗、試作宣稱、療效或促銷語
- [ ] 沒有翻案腔、宏大開頭、聊天殘留、意義尾巴、空泛總結
- [ ] 沒有破折號、提示性冒號、動詞名詞化、三項以上排比
- [ ] 散文沒有被硬切成清單，粗體每段至多一處
- [ ] 已發布內容未被順手重寫；只有本次修改的文字動過
