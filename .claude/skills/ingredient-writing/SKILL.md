# 食材寫作

把核准來源中與**單一食材**有關的事實，重述成繁體中文、臺灣用語的條目。條目解釋如何辨認、處理、保存與使用食材；單道料理的份量和步驟交給相關菜譜。文字是資料整理，不宣稱親自試作，也不沿用來源的句子或圖片。

欄位與草稿／發布條件以 [ingredient schema](../../../src/content/ingredient-schema.ts) 為準；來源核准與逐篇審閱依[食材編審流程](../../../.scratch/logo-ingredient-guide/issues/05-editorial-workflow.md)。可對照已審閱的[高麗菜](../../../content/ingredients/cabbage/ingredient.yaml)與[醬油](../../../content/ingredients/soy-sauce/ingredient.yaml)條目。

## 步驟

1. **界定範圍與來源**：確認條目是蔬菜、辛香料或調味料，以及談的是整類食材、特定部位、品種或產品。只採用站主對該條目核准的來源；候選來源先請站主核准。將實際採用的來源寫入 `content/ingredient-sources/<識別值>.yaml` 的 `sources` 清單，每項有 `title`、`url`。完成條件：每項準備寫入的事實都能指回清單中的核准來源。
2. **整理證據與限制**：逐項核對選用、處理、保存、用途；適用時再核對臺灣產期、酒精或過敏原。記下來源所指的產地、季節、品種、產品、包裝與保存狀態。來源說法衝突時選定採用口徑，並把理由交給站主審閱。完成條件：有依據的事實與其適用條件能逐項對上；缺少必填內容時保留草稿並回報缺口。
3. **撰寫條目**：依〈欄位寫法〉填入文字；相關菜譜只連已發布且確實使用或說明該食材的菜譜。草稿可暫無連結；已發布條目至少要有一篇。完成條件：每個欄位只陳述來源支持且符合條目範圍的內容。
4. **去 AI 味**：文字寫完後跑 [de-ai-voice](../de-ai-voice/SKILL.md)，只改腔調，來源事實、適用條件與臺灣用語不動。完成條件：該 skill 的自查清單全部成立。
5. **送審前核對**：逐項完成〈自查清單〉，讓站主審閱文字、來源對應、相關菜譜與圖片。修改產期、保存、用途或產品資訊時重新核對原頁及現行標示。完成條件：疑點與來源取捨已明列；新增條目在站主核准前維持草稿，既有公開條目的修改留在工作分支等待審閱。

## 欄位寫法

- **名稱與短介**：`title` 用臺灣常見名稱；`summary` 用一兩句交代食材特徵與本篇範圍。語氣平實，不寫療效、促銷語或沒有資料支持的保證。
- **選用 `selection`**：寫讀者能觀察或查到的挑選依據。談產品原料、酒精濃度、過敏原或標示時，點名該產品並提醒核對實際包裝；單一品牌的資料只代表該產品。
- **處理 `preparation`**：寫來源支持、在下廚前可操作的處理方式；區分整顆與切開、乾貨與泡發後等不同狀態。具體料理用量與連續步驟交給菜譜。
- **保存 `storage`**：把包裝、是否開封或切開、溫度等條件與建議放在同一句附近。來源沒有家庭保存方法時，明說來源未提供，並引導讀者依實際產品標示；保存天數只在來源與條件都明確時寫。
- **用途 `uses`**：描述有來源支持的料理用途或具體例子；一道料理的用法只當例子，不推成所有品種或產品的通則。替代建議與定量原則需要核准來源。
- **產期 `season`**：蔬菜的 `production` 只列來源支持的臺灣生產地區與月份；來源確認全年生產時才寫全年。`scope` 說明資料指主要產期或盛產期、產地與年度差異；市場供應資訊另行說明，不能代替國產產期。來源明確另列最佳賞味期時才填 `bestFlavor`；來源月份口徑不同時在 `scope` 說明採用哪一種。
- **食用提醒 `notices`**：來源能核對時才填酒精或過敏原，寫清食材或產品適用範圍及標示依據；不推論加熱後酒精會完全消失，也不把相似名稱的醬料視為相同配方。
- **圖片替代文字 `hero.alt`**：有圖時描述圖中實際可見的食材形態、數量與顏色；不把未畫出的品牌、部位或處理狀態寫進去。

## 自查清單

- [ ] 每項事實能指回該條目的核准來源；來源紀錄只列實際採用的網址
- [ ] 來源原句已重述，沒有試作、療效、保證或無依據的安全宣稱
- [ ] 名稱、短介、分類、選用、處理、保存、用途都已填寫；草稿／發布狀態正確
- [ ] 蔬菜的產地與月份、產期口徑、適用範圍一致；最佳賞味期另有來源依據
- [ ] 產品配方、保存與食用提醒只套用到來源支持的產品或狀態
- [ ] 相關菜譜與圖片替代文字符合實際內容；已發布條目至少連一篇已發布菜譜
- [ ] 全文使用繁體中文與臺灣用語；來源衝突、缺口及更新後重新核對的結果已交代
