# Logo 與食材介紹章節：實作票規格來源

Status: ready-for-agent

本目錄的實作票依[Logo 與食材介紹章節：決策階段規格](../logo-ingredient-guide/spec.md)拆分。該規格及其[Wayfinder 決策地圖](../logo-ingredient-guide/map.md)是產品決策來源；本檔只提供索引，不複製尚待決定的內容。

各票的 `Blocked by` 同時列出本目錄實作票與 Wayfinder 決策票。決策票未解決前，不得把 `ready-for-agent` 視為可開始正式實作。若首批條目清單超過單次實作可處理的範圍，先把類別票拆成可各自發布的條目批次，保持每批可獨立驗收。
