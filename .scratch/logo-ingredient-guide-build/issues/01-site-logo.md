# 01: 選定 Logo 套用全站

**What to build:** 讓讀者在現有網站各頁看見站主選定的 `CarlKitchen` Logo，於桌面與手機導覽列都能辨認站名並返回首頁；依定案規格處理需要的小尺寸用法。

**Blocked by:** [Logo 的識別方向與使用情境](../../logo-ingredient-guide/issues/01-logo-direction.md)。無本目錄內部依賴；食材章節的整體驗收決策不阻擋獨立 Logo 切片。

**Status:** done

- [x] 套用的是站主在 Logo 決策票選定的方向，英文站名與全站既有視覺語彙一致。
- [x] 桌面、手機及決策票要求的小尺寸情境可辨識、可閱讀；導覽中的首頁連結與鍵盤焦點正常。
- [x] 所有公開頁面的標誌呈現一致；以實際瀏覽器情境驗證版面與無障礙行為，站主目視確認視覺成果。
- [x] 專案既有必要檢查通過，品牌資產的用途與更新方式有簡要文件。

實作位於 `feat/logo-ingredient-guide` 工作目錄；站主依修正版手機、桌面截圖確認採用。`pnpm check`、`pnpm test`、`pnpm test:e2e` 通過。
