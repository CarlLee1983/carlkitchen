# 04: 食材與菜譜的探索銜接

**What to build:** 讓讀者依站主定案的關係，在食材介紹、相關菜譜及站內搜尋之間找到正確內容，同時保持菜譜與食材條目為不同類型的結果。

**Blocked by:** 03「食材介紹入口與瀏覽」；[食材與菜譜的導覽、連結及搜尋關係](../../logo-ingredient-guide/issues/06-discovery-links.md)。

**Status:** ready-for-agent

- [ ] 食材條目到菜譜，以及決策票選定的反向入口，都只連至已發布且仍存在的內容。
- [ ] 若決議納入搜尋，食材結果與菜譜結果可辨、同義詞及網址狀態符合決策，草稿不進索引；若決議維持菜譜限定搜尋，驗證食材頁不意外進入既有菜譜索引。
- [ ] 讀者可在手機、桌面與鍵盤操作下完成定案的探索流程；既有菜譜搜尋與分享網址不退化。
- [ ] 以實際建置輸出與瀏覽器測試驗證連結及搜尋邊界，必要檢查通過。
