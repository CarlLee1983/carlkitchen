# 03: 食材介紹入口與瀏覽

**What to build:** 讓讀者從網站導覽進入食材介紹章節，依站主選定的閱讀路徑找到已發布的食材條目，並從列表開啟條目與相關菜譜。

**Blocked by:** 02「第一篇食材條目從草稿到公開」；[食材與菜譜的導覽、連結及搜尋關係](../../logo-ingredient-guide/issues/06-discovery-links.md)。

**Status:** ready-for-agent

- [ ] 全站入口與章節頁採用已定案的名稱、分類和排序；讀者能找到第一篇已發布條目。
- [ ] 草稿不出現在導覽、章節清單、計數或公開建置輸出；沒有公開條目時有明確空狀態。
- [ ] 桌面、手機與鍵盤操作都能完成「導覽 → 章節 → 條目 → 菜譜」流程，頁面結構與焦點可供輔助技術理解。
- [ ] 以固定食材測試資料驗證列表與空狀態，必要檢查通過。
