# 06: 首批辛香料與調味料條目

**What to build:** 將站主選定且已核准來源的米酒、蔥、薑、蒜、蝦米及常用醬料逐篇整理為食材條目，讓讀者了解選用、處理與料理使用原則，並可前往相關菜譜。

**Blocked by:** 03「食材介紹入口與瀏覽」；[食材條目的內容契約與時令表述](../../logo-ingredient-guide/issues/04-content-contract.md)；[食材內容的來源紀錄與審閱流程](../../logo-ingredient-guide/issues/05-editorial-workflow.md)。

**Status:** ready-for-agent

- [ ] 覆蓋內容契約票定案的首批配料清單；若清單超過單次可驗收範圍，先拆成各自可發布的小批票。
- [ ] 每篇均有已核准的對應來源、站主審閱紀錄及符合內容契約的文字與圖片；未核准條目留在草稿。
- [ ] 米酒、辛香料、乾貨與醬料的用法按具體食材或產品說明，不把單一品牌配方概括到整類；過敏原與酒精提醒依定案規則呈現。
- [ ] 每篇可由章節入口找到，適用時連到已發布菜譜；草稿與內部來源不出現在正式輸出。
- [ ] 以內容檢查及完整讀者流程驗證發布結果，必要檢查通過。
