# 炒米粉肉絲部位：候選來源（已核准）

2026-10-07 站主選「里肌，備註可換梅花、五花」，核准下列三個部位指南；其餘僅作統計依據，未寫入來源紀錄。


- 結論提議：材料寫「豬肉絲（里肌肉）」，並在備註補一句「也可用梅花肉或五花肉，口感較油潤」。理由：部位指南一致說大里肌、小里肌適合「炒」（元氣網轉述農業部、食力、TVBS），里肌瘦、好切絲、快炒不易柴，也最好買。但要注意證據分歧：台式炒米粉食譜本身多半只寫「豬肉絲／肉絲」不指定部位（下方統計 9/12），有寫部位的反而是五花（2）與梅花（1），本次沒找到明寫「里肌肉絲」的台式炒米粉食譜。所以「里肌」是依部位用途推出的建議，不是炒米粉食譜的主流寫法。如果想貼近古早味（肉帶點油香），改寫「五花肉（三層肉）切絲」也有食譜依據。後腿肉也有來源說適合切絲／快炒，但多個來源描述它「較柴澀、纖維粗」，不建議當首選。

### 候選來源
- [x] https://health.udn.com/health/story/6037/7970283
  - 元氣網（聯合報系健康媒體），內容整理自農業部臉書粉絲專頁的豬肉部位圖解（半官方轉述，原始圖卡在臉書，未直接取得）。
  - 大里肌：肉塊完整、組織均一，排骨便當的排骨多採用此部位。小里肌（腰內肉）：無骨無筋、鮮嫩、油脂低、肉味淡，建議煎、炒、炸，不適合久燉。
  - 後腿肉：瘦肉多、油脂少，口感較柴澀，「常被用來做絞肉、肉羹或快炒」。五花肉（三層肉）：適合燉煮、紅燒。胛心肉瘦肉率高，可作絞肉。
- [x] https://www.foodnext.net/science/knowledge/paper/5470321486
  - 食力 foodNEXT（食品產業媒體）的豬肉部位指南。
  - 大里肌「較小里肌肉有咬勁，並且帶有適當的油花，因此適合煎、炸、炒」；小里肌（腰內肉）同樣「適合煎、炸、炒」。
  - 後腿肉：脂肪少、纖維較粗，「適合以切絲的方式來烹調或是長時間滷煮」。肩胛肉（胛心）、梅花肉適合烤、煎、燒烤。
- [x] https://health.tvbs.com.tw/nutrition/323087
  - TVBS 健康 2.0「圖解 11 種豬肉部位」（媒體整理）。
  - 大里肌「多做為豬排、燒烤、熱炒、燴煮或做成炸肉」（如糖醋里肌）；小里肌（腰內肉）肉質非常軟嫩，「多人會用來煮湯、快炒或是裹粉油炸」。
  - 肩胛肉（梅花／胛心）筋絡較多、吸水力強，適合做餡、丸子；後腿肉纖維粗、脂肪少、「比較不容易入口」，適合久紅燒。
