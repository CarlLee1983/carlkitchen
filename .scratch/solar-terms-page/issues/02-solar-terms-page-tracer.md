# 02: 節氣總覽頁的最小可用版本

**What to build:** 讀者可以從首頁節氣列點進 `/solar-terms/`，在一頁內依春夏秋冬、從立春起看到二十四節氣，每個節氣有現有插畫與一兩句說明，並落在該節氣的錨點；站內搜尋找得到節氣名。資料來自新的「節氣」結構化集合（ADR 0008），識別值與插畫檔名相同。

空集合規則：正式內容目錄沒有節氣資料時，不產生總覽頁、首頁節氣列不加連結；只要有資料就必須 24 筆齊全（齊全檢查在 05）。這讓程式可先合入，正式說明待來源核准後再上。

**Blocked by:** None（可立即開始，可與 01 平行）

**Status:** ready-for-agent

- [ ] 新增節氣集合與 schema（名稱、季節、說明、當令食材預留為可空陣列），無 `draft` 欄位
- [ ] 新增節氣內容目錄與節氣來源紀錄目錄兩個環境變數，比照 `TOPICS_DIR`／`TOPIC_SOURCES_DIR`；e2e 指向 24 筆齊全的 fixtures
- [ ] 總覽頁四季各有標題、立春起排序，每個節氣一個以識別值為 `id` 的區塊，插畫替代文字為「<節氣>節氣插畫」
- [ ] 首頁節氣列連到 `/solar-terms/#<識別值>`
- [ ] 總覽頁納入 Pagefind 索引，搜尋「冬至」可找到
- [ ] 空集合時不產生頁面、首頁不加連結（有測試）
- [ ] 手機寬度無橫向捲動；既有 a11y e2e 涵蓋新頁
- [ ] AGENTS.md 目錄結構與指令段補上節氣集合、來源紀錄目錄與環境變數
- [ ] `pnpm check && pnpm test && pnpm test:e2e` 通過
