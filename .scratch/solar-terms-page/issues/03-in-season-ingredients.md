# 03: 當令食材連結

**What to build:** 每個節氣可列出站主挑選的當令食材，連到已發布的食材條目；沒有當令食材的節氣不顯示空清單。頁面附「產期依地區與年度變動，僅供參考」提醒。內容檢查擋下指向不存在或未發布食材條目的連結。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 有當令食材的節氣顯示食材名稱並連到食材條目頁
- [ ] 當令食材為空的節氣不出現清單標題或空清單
- [ ] 頁面顯示「僅供參考」提醒
- [ ] `pnpm check:content` 對不存在或未發布的食材識別值回報 issue（單元測試，比照專題內容檢查測試）
- [ ] e2e fixtures 同時含有食材與無食材的節氣，兩種呈現都有測試
- [ ] `pnpm check && pnpm test && pnpm test:e2e` 通過
