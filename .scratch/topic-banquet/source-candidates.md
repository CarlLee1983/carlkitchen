## 查證限制

- **文化部《臺灣大百科全書》查不到**：`taiwanpedia.culture.tw` 從代理環境 DNS 解析失敗（curl 與 WebFetch 都是 `ENOTFOUND`），搜尋結果也沒有回傳辦桌詞條頁。站主若要用大百科，請用瀏覽器查「辦桌」詞條後把網址補進來。
- **國家文化記憶庫、文化資產局沒有可用頁面**：記憶庫搜尋只找到「總舖師的女兒」等影音或活動條目，沒有記錄出菜順序或菜色的文字；文資局國家文化資產網沒有以辦桌、總舖師或易牙祭登錄的民俗項目。
- **《重編國語辭典修訂本》頁面正文由 JavaScript 載入**：curl 只拿到外框，釋義是用 WebFetch 讀到的。頁面 HTTP 200、不需登入。
- **公部門頁面多是訪談轉述**：出菜順序與菜名寓意，幾乎都是公部門刊物（《高雄畫刊》、外交部《台灣光華雜誌》、移民署網站、中研院電子報）引述總舖師或研究者的說法，沒有一份是官方「標準菜單」。寫的時候要寫成「某地某師傅這樣做」或「常見安排」，不能寫成全臺通則。
- **年年有餘找不到辦桌脈絡的依據**：公部門頁面只把「魚＝年年有餘」放在**年夜飯、年菜**脈絡；講到辦桌的魚，說法是另一套（見 2-4）。
- **甜湯收尾找不到依據**：公部門頁面寫的是「甜點、水果」收尾，或內門婚宴以魚丸湯收尾，沒有一份寫「甜湯」；也沒有任何來源把紅豆湯列為辦桌菜（見 2-5、3-3）。
- 楊桃美食網的四個菜譜頁用 `.claude/skills/recipe-making/scripts/fetch-ytower.sh` 抓取並轉碼，四頁都沒有提到辦桌或宴客；它們只能支持「怎麼做」，不能支持「這是辦桌菜」。

## 題目建議

〈辦桌：流水席上的一桌菜〉的「流水席」要再想一下。教育部國語辭典的流水席是「酒菜不斷、客人隨到隨吃、吃完就走」的宴客方式；《光華》2023 也只把流水席用在宮廟慶醮宴。婚宴要發帖、排座、按道上菜，不是流水席。建議改成〈辦桌：一桌菜的出菜順序〉或〈辦桌：總舖師的一桌菜〉，流水席放進篇章 1 當作辦桌的一種形式來介紹。

## 篇章 1：辦桌是什麼

### 1-1｜「辦桌」的意思

預計陳述：辦桌是臺語，指請廚師到家裡或指定地點掌廚、準備酒菜宴客；主人辦桌，客人「食桌」。

- [x] C1 教育部《臺灣台語常用詞辭典》「辦桌」（pān-toh）
  - 動詞，設宴、辦酒席，釋義寫明是外燴的人到家裡掌廚備菜宴客；分類在「婚喪喜慶」。例句拿辦桌和上餐廳對比。
- [ ] C4 教育部《重編國語辭典修訂本》「辦桌」
  - 華語辭典也收這個詞：請外面的專人到家裡掌廚、準備酒菜宴客；例句是里長兒子結婚席開百桌。
- [x] C12 中研院《數位文化電子報》第 30 期
  - 說明「辦」是辦理、「桌」指桌上的菜；主人辦桌、客人去「食桌」。另提辦桌有時間、地點、人員都不固定的特性。

判定：**成立**。「食桌」的說法也可對到 C1 同站的「桌」詞條（例句有「食桌」），不另列。

### 1-2｜總舖師是誰、做什麼

預計陳述：主持辦桌的大廚叫總舖師，從採買、菜單到上菜流程都由他主導；底下有大工、水腳分工。

- [x] C2 教育部《臺灣台語常用詞辭典》「總舖師」（tsóng-phòo-sai）
  - 名詞，指大廚師；近義詞有「總舖」「廚子」。辭典用字是「總舖師」。
- [x] C5 《高雄畫刊》〈辦桌文化 正趣味〉（2010-05）
  - 掌理外燴辦桌的大廚叫總舖師，從食材採買到上桌都由他負責。
- [x] C11 移民署〈臺灣辦桌文化〉
  - 菜色由總舖師掌廚，主導整場宴會的菜色與流程。
- [x] C13 國立臺灣歷史博物館〈鄰里婦女「做水腳」〉
  - 總舖師決定菜色與流程；底下的學徒、幫廚叫「大工」，多為男性；洗菜、備料、端盤、洗碗的幫手叫「水腳」，多為女性，中南部稱水腳，北部常叫小工、女工。
- [x] C12 中研院《數位文化電子報》第 30 期
  - 南部也稱「刀煮師傅」。

判定：**成立**。用字建議依 C2 寫「總舖師」，全篇統一；其他來源寫「總鋪師」，引用機構名稱時照原文。「刀煮師」是南部稱呼（C12；C7 也提到內門第一代刀煮師），可提一句，不要寫成全臺通稱。

### 1-3｜路邊搭棚、現場開伙

預計陳述：辦桌常在路邊、廟口廣場或活動中心搭棚，旁邊架爐灶現煮。

- [x] C5 《高雄畫刊》〈辦桌文化 正趣味〉
  - 在馬路邊搭棚、擺圓桌辦桌，被描述成臺灣很道地的飲食風景。
- [x] C11 移民署〈臺灣辦桌文化〉
  - 以搭棚方式設宴，場地常是路邊、廟口廣場、里民活動中心，旁邊架爐灶與備菜桌現場烹煮。
- [x] C10 《光華》〈湯湯水水話台菜〉（1995）
  - 家門前、馬路邊、廣場、活動中心或學校禮堂，棚子一搭、桌椅擺上，總舖師就地開煮。

判定：**成立**。

### 1-4｜辦桌的場合

預計陳述：婚宴、壽宴、彌月、入厝、廟會、喪事、尾牙都會辦桌。

- [x] C5 《高雄畫刊》〈辦桌文化 正趣味〉
  - 受訪總舖師說，以前不只婚嫁，長輩慶生、新生兒滿月、入厝、祭神、親友往生、工廠尾牙都請總舖師辦桌。
- [x] C10 《光華》〈湯湯水水話台菜〉
  - 節慶拜拜、訂婚、結婚、生日、彌月、喬遷、喪禮都會辦桌宴客。
- [x] C12 中研院《數位文化電子報》第 30 期
  - 辦桌種類很多：宗教上的天子宴、齋醮宴、普渡宴；生命禮俗的結婚、滿月、壽誕、喪禮；還有入厝、尾牙、春酒。

判定：**成立**。

### 1-5｜流水席

預計陳述：流水席是酒菜不斷、客人隨到隨吃的形式；不是所有辦桌都是流水席。

- [x] C3 教育部《重編國語辭典修訂本》「流水席」
  - 酒菜持續供應，客人隨到隨吃、吃飽就走的宴客方式；例句是建醮時鎮上擺了三天三夜流水席。辭典釋義本身沒有限定臺灣。
- [x] C9 《光華》〈宴會風光 來！呷辦桌！〉（2023）
  - 宮廟為神明壽誕辦的慶醮宴講究流水席：信眾認購幾桌，客人一攤吃完換一攤，新客人入座就換一副碗筷，不收紅包。

判定：**部分成立需修正**。流水席有依據，但來源只把它用在建醮、宮廟慶典；婚宴等發帖排座的辦桌不是流水席。題目與內文都不要把「辦桌」和「流水席」畫上等號（見〈題目建議〉）。

### 1-6｜從鄰里互助到專業團隊

預計陳述：早年主家出食材、鄰居借桌椅幫忙，總舖師只負責煮；後來總舖師連桌椅、爐具、餐具一起包辦。

- [x] C5 《高雄畫刊》〈辦桌文化 正趣味〉
  - 早年鄉下由主家出食材、鄰居搭棚借鍋椅，總舖師只管烹調；後來外燴團自備爐具餐具，採購、運輸、租桌椅合為一體，辦桌成了專業。
- [x] C6 《高雄畫刊》〈總鋪師的藝術〉（2017）
  - 1960 年代內門的「郭三湯」組合開始自備桌椅、餐具廚具到現場，改變了主人籌備、鄰居幫忙的舊做法。
- [x] C12 中研院《數位文化電子報》第 30 期
  - 日治前後桌椅靠親友鄰居出借；民國 60 年後才有布棚、桌椅碗盤出租等專業分工。

判定：**成立**。年代只能照來源寫並具名（「內門的郭三湯在 1960 年代……」），C6 與 C12 的時間點不同，不要合併成一句通則。

### 1-7｜內門：總舖師原鄉

預計陳述：高雄內門被稱為總舖師原鄉，從業人數多。

- [x] C5 《高雄畫刊》〈辦桌文化 正趣味〉（2010）
  - 當時內門一萬多人口裡有超過 150 組人以總舖師為業，約每五戶就有一戶靠辦桌維生。
- [ ] C8 高雄市內門區公所〈總鋪師原鄉〉
  - 同樣的 150 組、五戶一戶數字；另說內門山多田少、農耕不易，陣頭團練的點心慢慢演變成辦桌行業。
- [x] C7 《高雄畫刊》〈我辦桌我驕傲〉（2019）
  - 內門是總舖師的故鄉，最盛時期超過一百位總舖師；第一代「刀煮師」幾乎都是女性。

判定：**成立**，但數字要帶年份與出處（C5 是 2010 年的報導）。若篇幅有限，這節可整段省略，不影響主線。

### 1-8｜「外燴」與辦桌的關係

預計陳述：辦桌是一種外燴。

- [x] C11 移民署〈臺灣辦桌文化〉
  - 直接說辦桌是一種外燴形式。
- [x] C12 中研院《數位文化電子報》第 30 期
  - 從管理學角度，辦桌就是一般說的外燴。
- [x] C7 《高雄畫刊》〈我辦桌我驕傲〉
  - 受訪的內門總舖師認為辦桌和外燴精神不同：辦桌每道菜都在現場開鍋，外燴可以先做好。

判定：**部分成立需修正**。來源口徑衝突。建議寫「辦桌請的是到府或到場掌廚的廚師團隊」，不下「辦桌就是外燴」的定義；若要提外燴，寫成「也常被歸為外燴」。

### 1-9｜辦桌起源年代

預計陳述（若要寫）：辦桌可以追溯到清代或更早。

- [x] C9 《光華》〈宴會風光 來！呷辦桌！〉
  - 中研院台史所曾品滄從帳簿、日記看到清康熙時期臺灣人就喜歡請廚師到家裡辦酒席。
- [x] C12 中研院《數位文化電子報》第 30 期
  - 寫辦桌可追溯到 17 世紀明鄭、清代，並引 1720 年《臺灣縣志》說宴客花費很高。

判定：**部分成立需修正**。兩個來源的年代說法不同，也都是研究者觀點。任務要求不推論起源年代，建議**不寫起源年代**；真要寫，只能具名引述（「曾品滄的研究提到……」），不寫成定論。

## 篇章 2：一桌菜的出菜順序

### 2-1｜冷盤開場

預計陳述：第一道通常是冷盤拼盤。

- [x] C11 移民署〈臺灣辦桌文化〉
  - 菜不是一起上，第一道通常是冷盤（例如涼拌海蜇皮、烏魚子），冷盤放得住，客人晚到也不怕。
- [x] C6 《高雄畫刊》〈總鋪師的藝術〉
  - 照片圖說寫辦桌第一道是冷盤；當天婚宴開席時第一道上五子拼盤。
- [x] C9 《光華》〈宴會風光 來！呷辦桌！〉
  - 喜宴第一道從雙喜、四喜拼盤開始。

判定：**部分成立需修正**。冷盤開場有依據，但要加例外：C9 說壽宴、神明壽誕宴第一道是豬腳麵線，起家宴（喬遷或喪事後）第一道是全雞；C12 也說結婚或入厝的第一道一定是全雞。寫成「喜宴常以冷盤開場，但場合不同第一道也不同」。注意 C9 與 C12 對「結婚第一道」說法不一致（拼盤或全雞），建議只寫壽宴與起家宴的例外，結婚不下定論。

### 2-2｜羹湯在前、一盤菜一碗湯

預計陳述：冷盤之後常上羹湯；傳統辦桌菜和湯交替上。

- [x] C9 《光華》〈宴會風光 來！呷辦桌！〉
  - 喜宴第二道是雜菜羹或魚翅羹（「二路菜」），受訪師傅說羹的高湯要熬四到五小時。
- [x] C10 《光華》〈湯湯水水話台菜〉
  - 林添盛說傳統辦桌是「一盤菜、一碗湯」輪流上：以前沒有飲料要靠湯解渴；柴火、炭火火力不夠不好快炒，蒸燉比較方便；湯可以先備好，也能隨人數增減。
- [x] C11 移民署〈臺灣辦桌文化〉
  - 冷盤之後陸續上羹湯、海鮮、肉品等熱菜。

判定：**成立**。「一盤菜一碗湯」寫成林添盛所說的傳統做法，標明是 1995 年的訪談。

### 2-3｜道數

預計陳述（常見說法）：辦桌固定 12 道菜。

- [x] C10 《光華》〈湯湯水水話台菜〉
  - 林添盛說辦桌不一定是 12 道，只要雙數就好；宜蘭有名的 36 道其實是同一道菜一直添。
- [x] C9 《光華》〈宴會風光 來！呷辦桌！〉
  - 喜事道數取偶數、喪事取奇數；曾品滄說臺灣宴會常有 12 到 16 道。
- [x] C6 《高雄畫刊》〈總鋪師的藝術〉
  - 該場婚宴是一桌十道菜，另加一盤水果、一盤甜點。

判定：**部分成立需修正**。「固定 12 道」有來源直接反駁；改寫成「道數不固定，喜事習慣取雙數」。

### 2-4｜魚的寓意（年年有餘？）

預計陳述（常見說法）：辦桌上魚象徵年年有餘。

- [x] C9 《光華》〈宴會風光 來！呷辦桌！〉
  - 有些家庭訂婚宴上魚時，男方親戚會直接離席不道別，民間說法是「魚」諧音「餘」、給對方留餘地；受訪師傅則解為魚游來游去、親戚「有來有去」；所以師傅會把魚排到最後才上。
- [x] C12 中研院《數位文化電子報》第 30 期
  - 1935 年出生的受訪者回憶日治時期路邊辦桌，最後一道菜一定是一條魚，再來是甜點。
- [ ] C16 教育百科「年年有餘」（不建議收）
  - 辭典釋義是過年吉祥話，例句是年夜飯一定有魚；講的是年菜，不是辦桌。

判定：**無依據建議刪除**「辦桌的魚象徵年年有餘」。公部門來源只在年夜飯脈絡講年年有餘。可以改寫成 C9 的訂婚宴習俗（魚上桌時男方離席、魚排在後面），並寫明是「有些家庭」的習俗、說法不只一種。

### 2-5｜甜湯收尾

預計陳述（常見說法）：辦桌最後以甜湯收尾，象徵甜甜蜜蜜或圓滿。

- [x] C11 移民署〈臺灣辦桌文化〉
  - 尾聲先來一碗熱雞湯，最後用甜點和水果結尾。
- [x] C6 《高雄畫刊》〈總鋪師的藝術〉
  - 一桌十道菜之外另有一盤水果、一盤甜點。
- [x] C12 中研院《數位文化電子報》第 30 期
  - 內門婚宴最後一道是魚丸湯，代表圓滿，但現在已經很少人準備。
- [x] C10 《光華》〈湯湯水水話台菜〉
  - 林添盛為兒子辦的婚宴菜單最後一道是「果汁點心」；日治時期菜單最後是「完席酥餅」。

判定：**部分成立需修正**。「尾聲上甜點、水果」成立；「甜湯」與其「甜蜜」寓意找不到依據，建議刪掉寓意，改寫成「尾聲常是甜點與水果」。「圓滿」只有 C12 用在內門婚宴的魚丸湯，要寫就具名寫內門的例子。C15（移民署轉載 Heho）也說甜點水果收尾「象徵圓滿結束」，但它是媒體轉載，不建議當依據。

### 2-6｜其他菜名寓意（可選）

預計陳述：有些菜色有諧音寓意或婚宴禁忌。

- [x] C9 《光華》〈宴會風光 來！呷辦桌！〉
  - 起家宴第一道全雞，「雞」與臺語「家」諧音；壽宴第一道豬腳麵線象徵長壽。
- [x] C10 《光華》〈湯湯水水話台菜〉
  - 林添盛說訂婚席依籍貫不同：泉州人要兩盤壽麵、同安人要湯圓、客家人要芹菜、韭菜、菜頭；喜宴避鰱魚、鱉、蟳、鴨等，各有諧音或象徵理由。
- [x] C12 中研院《數位文化電子報》第 30 期
  - 內門林瑞章師傅說封肉用腿庫，取步步高升；喪家辦桌的封肉切三角形。

判定：**成立**（皆為受訪者說法）。寫的時候標明是哪位師傅或研究者、哪種場合，不寫成全臺都這樣；C10 本身就說明各族群習俗不同，正好用來提醒「不是處處一樣」。

## 篇章 3：家裡做得出的辦桌菜

### 3-1｜清蒸魚（`steamed-fish`，已發布）

預計陳述：清蒸魚是辦桌常見的魚料理，家裡用一尾鱸魚就能做。

- [x] C14 臺南400〈流動的盛宴─來辦桌〉系列報導18（2024-08-30）
  - 介紹臺南一家外燴宴席時提到「清蒸魚」是目前外燴宴席常見的做法，該師傅改成糖醋魚捲求新。
- [x] C11 移民署〈臺灣辦桌文化〉
  - 常見主菜列了清蒸石斑。
- [x] R1 楊桃美食網「清蒸魚(11)」（已是菜譜核准來源）
  - 《快樂廚房雜誌》第 89 期；銀花鱸魚一尾，大火蒸 15 分鐘，鋪蔥薑辣椒絲淋熱油，再淋蠔油醬汁。頁面沒有提到辦桌。
- [x] R2 楊桃美食網「清蒸鱸魚」（已是菜譜核准來源）
  - 鱸魚蒸約 10 分鐘，淋蒸魚醬油、鋪蔥薑辣椒絲、淋熱油。頁面沒有提到辦桌。

判定：**成立**。辦桌上常見的是石斑等魚，站上版本是鱸魚；寫「在家可以用鱸魚做同樣的清蒸」，不說辦桌都用鱸魚。

### 3-2｜肉羹湯（`pork-thick-soup`，已發布）

預計陳述：羹類是辦桌前段的菜，肉羹是總舖師的拿手菜之一；站上是電鍋版本的家常做法。

- [x] C9 《光華》〈宴會風光 來！呷辦桌！〉
  - 喜宴第二道是雜菜羹或魚翅羹。
- [x] C7 《高雄畫刊》〈我辦桌我驕傲〉
  - 內門總舖師推薦的拿手菜是肉羹，以大骨、時蔬燉高湯，加扁魚調味。
- [x] C6 《高雄畫刊》〈總鋪師的藝術〉
  - 婚宴開席前師傅在確認肉羹的調味。
- [x] R3 楊桃美食網「肉羹湯(2)」（已是菜譜核准來源）
  - 《快樂廚房雜誌》第 105 期；雞骨與柴魚片用電鍋煮湯底，加香菇、紅蘿蔔、筍絲與肉羹，勾芡調味。頁面沒有提到辦桌。

判定：**成立**。注意站上版本是電鍋家常做法，湯底是雞骨加柴魚，不是辦桌師傅的大骨扁魚高湯；寫成「辦桌常見羹湯，在家可以做簡單的電鍋版」。

### 3-3｜紅豆湯（`red-bean-soup`，已發布）

預計陳述（原構想）：紅豆湯是辦桌收尾的甜湯。

- [x] R4 楊桃美食網「紅豆湯(2)」（已是菜譜核准來源）
  - 紅豆 300 g 加水 1200 cc 泡約 2 小時，煮開撈浮沫後小火約 40 分鐘，加糖燜 15 分鐘。頁面沒有提到辦桌。

判定：**無依據建議刪除**「紅豆湯是辦桌菜」。找不到任何來源說辦桌會上紅豆湯（2-5 的來源只寫甜點、水果）。建議改寫成編輯建議：「辦桌尾聲常上甜點；在家擺一桌菜時，可以用一碗紅豆湯當收尾的甜湯」——寫成建議，不寫成辦桌的事實。站主若覺得這樣太牽強，也可以不連紅豆湯。

### 3-4｜鳳梨蝦球（`pineapple-shrimp-balls`，草稿）

不連結。專題規定只連已發布菜譜；若要提，待菜譜發布後再送審專題。沒有找到公部門來源把鳳梨蝦球列為辦桌菜（C8 只提到鳳梨是內門在地食材），發布後要連也需另找依據。
