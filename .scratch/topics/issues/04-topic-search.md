# 04: 專題進搜尋

**What to build:** 讀者搜尋「逆紋」「爆香」這類詞時也找得到專題，並能從結果分辨哪些是專題、哪些是菜譜。用菜譜分類篩選時，結果照舊只有菜譜。規格見[專題規格](../spec.md)。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 專題頁的標題、短介、內文進 Pagefind 索引；圖片替代文字照舊排除
- [ ] 專題頁帶 `type:topic` 篩選標記；既有的菜譜分類篩選語意不變，結果不含專題
- [ ] 搜尋結果能分辨專題和菜譜
- [ ] 草稿專題不進索引
- [ ] e2e 涵蓋：以只出現在固定專題內文的詞搜尋能找到該專題；套用菜譜分類篩選時不出現專題
- [ ] `pnpm check && pnpm test && pnpm test:e2e` 通過
