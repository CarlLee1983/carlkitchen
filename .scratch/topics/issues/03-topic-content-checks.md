# 03: 專題內容檢查

**What to build:** 站主跑 `pnpm check:content` 時，專題和菜譜、食材條目一起受檢查。以下情況都會被報出來：
- 已發布專題沒有查證來源
- 段落對照引用了沒列出的網址
- 封面圖規格不符
- 替代文字提到餐具
- 草稿或核准來源網址出現在建置輸出

這樣沒查證的內容不會上線，部署流程也不必改。規格見[專題規格](../spec.md)。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 每篇專題對應一份內部來源紀錄，放在內容集合與公開輸出之外，內容是 `sources`（`title`、`url`）與段落對照（小節標題對應到來源網址）；目錄可用環境變數切換，比照 `SOURCES_DIR`
- [ ] 已發布專題缺來源紀錄或沒有核准來源時報錯；草稿不受限
- [ ] 段落對照中的網址不在 `sources` 裡時報錯
- [ ] 封面圖不是 WebP、不是 1536×1024 或超過 300 KB 時報錯；替代文字提到餐具時報錯
- [ ] 草稿專題出現在建置輸出、核准來源網址洩漏到建置輸出時報錯
- [ ] `--launch` 的候選池門檻不受專題影響
- [ ] 每條規則都有內容檢查測試，比照既有的食材條目、來源紀錄、圖片、洩漏測試
- [ ] 測試用固定專題補上來源紀錄；`AGENTS.md` 的 `check:content` 說明補上專題
- [ ] `pnpm check && pnpm test && pnpm check:content` 通過
