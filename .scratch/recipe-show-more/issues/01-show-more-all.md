# 01: 「全部」清單的顯示更多

**What to build:** 讀者進首頁、沒有篩選與搜尋字詞時，菜譜清單只顯示第一批；清單之後有原生按鈕「再顯示 {n} 道（還有 {剩餘} 道）」，按一次多顯示一批，全部顯示後按鈕消失。按下後焦點移到新出現的第一道菜的連結。沒有 JavaScript 時清單完整可見。每批數量在建置時決定（預設 20），寫進首頁標記供腳本讀取。

另建一份專測顯示更多的 e2e 站台：沿用 `E2E_SITE=meal` 的模式，以預設 e2e 固定菜譜、每批 1 道（固定菜譜 4 道，讓按鈕文字至少更新幾次）建置到獨立輸出目錄與 port，只跑新的顯示更多規格；預設站台與現有規格不動。規格見 `.scratch/recipe-show-more/spec.md`。

**Blocked by:** None（可立即開始）

**Status:** ready-for-agent

- [ ] 截斷規則是首頁工具裡的純函式：輸入可見列總數、每批數量、目前要顯示的數量（可未設定）；輸出實際顯示列數（夾在一批與總數之間）、剩餘列數、下一次再顯示的數量；另有「按一次」的下一狀態，回傳新出現的第一列位置
- [ ] 單元測試涵蓋總數小於、等於、大於一批，最後一批不足，未設定與超出範圍的輸入
- [ ] 每批數量由建置環境變數覆寫（預設 20），只在一處定義
- [ ] 建置輸出全部列且可見；腳本初始化時才以 `hidden` 收起超出第一批的列
- [ ] 按鈕文字照實寫出本次再顯示的道數與剩餘道數；剩餘 0 時隱藏；總數不超過一批時從不出現
- [ ] 「共 N 道」狀態文字不變
- [ ] 按下後焦點移到新出現的第一列的連結
- [ ] `pnpm test:e2e` 依序建置並跑三份站台；`pnpm check:merge --e2e` 亦同
- [ ] 新 e2e 規格（每批 1 道，讓按鈕文字在固定菜譜下至少更新一次）驗證：初始只顯示 1 道與按鈕、按下後多 1 道並移動焦點、按鈕文字更新、到底後消失、展開後切換篩選回到一批、停用 JavaScript 時全部可見
- [ ] `pnpm check && pnpm test && pnpm test:e2e` 通過
