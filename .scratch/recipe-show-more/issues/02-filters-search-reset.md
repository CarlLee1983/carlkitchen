# 02: 篩選與搜尋結果套用顯示更多，換條件重設

**What to build:** 讀者按性質篩選或輸入搜尋字詞時，只要結果超過一批，同樣只先顯示第一批並出現按鈕；截斷依畫面上的清單順序計算，搜尋時是相關度排序，命中的專題列也算在一批內。讀者切換篩選、改搜尋字詞或清除搜尋時，清單回到只顯示第一批。清單為空時沒有按鈕，空狀態訊息照舊。

**Blocked by:** 01（「全部」清單的顯示更多）

**Status:** ready-for-agent

- [ ] 截斷是首頁 render 決定可見列與順序之後的最後一步，不改變篩選與搜尋本身的結果
- [ ] 搜尋時專題列與菜譜列依相關度一起計入一批
- [ ] 換篩選、改字詞、清除搜尋後只顯示第一批，按鈕文字依新清單更新
- [ ] 清單為空時按鈕隱藏，空狀態訊息不變
- [ ] 顯示更多 e2e 規格驗證：篩選結果超過一批時截斷、展開後換篩選重設、展開後改搜尋字詞重設、搜尋結果超過一批時截斷、空結果沒有按鈕
- [ ] `pnpm check && pnpm test && pnpm test:e2e` 通過
