# 03: 上一頁與重新整理保留展開數量

**What to build:** 讀者展開清單後點進某道菜譜，按上一頁回到首頁時，維持離開前的展開數量，捲動位置也回到原處；重新整理首頁時同樣維持。以新連結進入首頁時只顯示第一批。展開數量存在目前這筆瀏覽紀錄的狀態（history state），不進網址、不進 sessionStorage，所以分享出去的網址只帶篩選與搜尋字詞。

**Blocked by:** 01（「全部」清單的顯示更多）、02（篩選與搜尋結果套用顯示更多，換條件重設）

**Status:** ready-for-agent

- [ ] 按下按鈕時把新的展開數量寫進目前瀏覽紀錄的狀態，網址不變
- [ ] 首頁初始化時讀取保存值，交給純函式夾在一批與目前總數之間後套用；菜譜減少使保存值超過總數時不出錯
- [ ] 換篩選或搜尋字詞寫網址時清掉保存的展開數量（現有寫網址流程以 `history.replaceState` 寫入，不得保留舊值）
- [ ] 列顯示後捲動位置落在原處（交給瀏覽器捲動還原，必要時在列顯示後再還原一次）
- [ ] 單元測試補保存值超過總數、小於一批的情形
- [ ] 顯示更多 e2e 規格驗證：展開後進菜譜再上一頁仍維持數量、重新整理仍維持、換條件後再上一頁不帶回舊數量、網址不出現展開數量
- [ ] `pnpm check && pnpm test && pnpm test:e2e` 通過
