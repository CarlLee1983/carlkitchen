## `hot-and-sour-soup` 酸辣湯

- 分類提議：湯，以湯汁、勾芡和蛋花為主要呈現。
- 蔬菜與蛋白質標記提議：均為 `false`，依本站湯品不參與非湯菜平衡標記的規則；不是聲稱食材不含蛋白質。
- 配菜候選提議：`mealCandidate: true`，適合家常套餐的湯品位置。
- 兩個食譜均為台式酸辣湯，不是泰式酸辣湯；2026-10-07 已用公開網頁與原始 HTML 核對，HTTP 200、不需登入、有完整文字步驟。

### 食譜候選

- [x] https://icook.tw/recipes/279840
  - 愛料理官方品牌廚房，推薦主來源。標示 4 人份、45 分鐘，5 個步驟；豬肉絲、熟竹筍、黑木耳、豆腐、鴨血與蛋，以白醋和白胡椒調味。醃肉 20 分鐘，先炒肉再煮湯、勾芡與加蛋。高湯及多數調味有數字；紅蘿蔔、竹筍、鴨血、豆腐仍使用半條、半個、塊、盒等份量，油及芡水未量化，未標爐火強度。這些缺口不可假稱直接公制換算。
- [x] https://icook.tw/recipes/363456
  - 小磨坊，交叉參考。標示 2 人份、15 分鐘，6 個步驟；沒有竹筍，白醋與烏醋並用，肉絲與鴨血先汆燙。主料全部有克數或顆、支數，芡水粉水比為 1:2；調味較重。材料寫熱開水、步驟寫高湯，有內部不一致；蛋液加入後即關火，缺安全熟度判準。品牌名稱需改寫為一般品項，不能把複方辣胡椒粉逕稱純白胡椒粉。

### 食安補充候選

- [x] https://www.foodsafety.gov/blog/salmonella-and-eggs
  - 美國政府食安指引，2026-10-07 已開啟且 HTTP 200。說明蛋應煮熟，以及含肉蛋料理的安全中心溫度為 165°F（約 74°C）。僅用來補充安全熟度，不作口味或份量來源；不把「下蛋後立刻關火」直接搬入菜譜。
