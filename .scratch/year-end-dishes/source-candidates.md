## 查證限制

- **教育部《臺灣台語常用詞辭典》這次讀不到正文**。`sutian.moe.edu.tw` 的憑證已過期，curl 與網頁擷取都失敗（SSL error 60／HTTP 500）。搜尋索引看得到「尾牙」「做牙」「圍爐」的釋義，但不能當成已親自讀過。三個詞條列在文末〈待核〉，請站主用瀏覽器打開後再決定要不要補進核准來源。
- **尾牙和圍爐不是同一餐**。文獻館記的家庭「食尾牙」是潤餅、刈包；菜色寓意（魚、全雞、長年菜）都出現在除夕圍爐。題目可以兩件事都寫，不能合成一張菜單。
- **站上三道「可先做」的菜，沒有一份來源說它們是年菜**。清蒸魚可以連到「除夕有魚」；滷雞腿不是來源說的全雞；台式滷肉、紅酒燉牛肉沒有年菜記錄。
- **「前一天先做」沒有習俗依據**。找得到的是：客家炆菜一次做、可以再熱；食藥署談年菜復熱要到 70°C、不要反覆熱。這是做法與食安，不是「年菜慣例是前一天做好」。
- 文化部《臺灣大百科全書》這次沒有找到可直接打開的尾牙、圍爐或年菜詞條，清單沒有收。

## 建議先改的範圍

1. 菜色寓意只放在除夕圍爐，不放在尾牙。尾牙寫成臘月十六的作牙，以及商家犒賞員工的宴；家庭食尾牙若要寫，只寫潤餅、刈包，而且站上沒有這兩道菜譜，正文不連菜譜。
2. 「食雞起家」只對全雞。滷雞腿不要當成這句話的例子。
3. 怎麼選改成：除夕要上一尾完整的魚時，用現蒸（清蒸魚）；想一次做、之後再熱的，用炆、滷這類久煮的菜，並寫食藥署的復熱條件。紅酒燉牛肉沒有年菜依據，建議不連；若仍要連，只能當「家裡可再熱的燉菜」例子，不能寫成圍爐菜。

## 篇章 1：尾牙和圍爐不是同一件事

### 1-1｜尾牙是一年最後一次作牙

預計陳述：農曆每月初二、十六作牙；二月初二是頭牙，十二月十六是尾牙。商家會在這段時間請客、犒賞員工。

- [x] C1 臺灣文獻館〈尾牙宴〉
  - 初二、十六作牙；二月初二稱頭牙，十二月十六是一年最後一次，稱尾牙。引《臺灣歲時記》：燒土地公金、祭福德正神，門前設長凳、供五味碗饗地基主。商家行號也在這段期間宴請員工，犒賞一年的辛勞。

判定：**成立**。寫成文獻館轉述的歲時記錄，不寫成現在每家公司都在臘月十六當天辦。

### 1-2｜雞頭指向誰：舊俗，文獻館說已經沒有了

預計陳述：以前若來年不續聘，席上把雞頭對著那個人。這個做法現在已經消失，尾牙宴變成年終犒賞。

- [x] C1 臺灣文獻館〈尾牙宴〉
  - 寫明來年不準備續聘的員工，筵席中以雞頭對準他；接著寫這個習俗現今已完全絕跡，尾牙宴反而成為公司行號年終前犒賞、慰留員工的場合。

判定：**成立，建議只寫一句**。這是人事舊俗，不是菜色寓意。不展開，也不寫成現在還有人這樣做。

### 1-3｜家裡食尾牙的食物是潤餅和刈包

預計陳述：文獻館記的家庭食尾牙，主要是潤餅和刈包，不是圍爐那一桌魚和雞。

- [x] C1 臺灣文獻館〈尾牙宴〉
  - 傳統習俗是全家人一起食尾牙。潤餅皮包豆芽、筍絲、豆乾、蒜、蛋燥、虎苔、花生粉、番茄醬等；刈包裡是三層肉、鹹菜、筍乾、香菜、花生粉。

判定：**成立，而且站上連不到**。沒有已發布的潤餅或刈包菜譜。正文可以提這兩樣食物的名稱，不寫完整做法，也不連菜譜。

### 1-4｜圍爐是除夕的年夜飯

預計陳述：圍爐是除夕晚上全家一起吃年夜飯。早年餐桌下放火爐；現在有人用桌上的火鍋代替。除夕也稱廿九暝或三十暝。下午先辭年祭祖，晚上才入席。

- [x] C2 傳藝中心〈只要背好這幾個〉
  - 除夕先祭拜祖先，再圍爐吃年夜飯。早年在餐桌下放置小火爐取暖，並把火爐說成全家團圓、興旺的象徵。
- [x] C3 國家文化記憶庫藏品說明
  - 除夕俗稱廿九暝或三十暝。下午準備牲禮祭拜祖先與神明，稱為辭年。晚餐全家圍圓桌吃年夜飯。吃飯時桌下放火爐，爐周灑銅錢，稱為圍爐；現在沒有火爐，改以桌上的火鍋代替。

判定：**成立**。兩份都寫桌下火爐。銅錢、火鍋代替只見於 C3，寫的時候標明是這份藏品說明的說法。不把火鍋寫成全臺圍爐的固定形式。

## 篇章 2：圍爐菜色的說法

### 2-1｜魚：年年有餘，而且要留一點

預計陳述：魚和「餘」同音，除夕會有魚。有的做法是留到除夕過後再吃，或只吃一半，表示還有餘。另有說法要求魚要完整，不要切斷。

- [x] C4 水產試驗所〈年年慶有餘〉
  - 這是一道蒸吳郭魚。附註寫：魚與餘同音，是除夕必有的一道菜；傳統須留到除夕過後吃，或只吃一半，象徵有餘。
- [ ] C6 食農平臺〈長年百歲菜－芥菜〉
  - 除夕餐桌上，魚象徵年年有餘。同一段還列了蘿蔔糕、年糕、發糕（年年高升）、韭菜（長長久久）、火鍋裡的魚丸貢丸花枝丸（團團圓圓）。
- [ ] C7 移民署〈臺灣過年應景年菜〉
  - 過年吃魚象徵年年有餘。蒸、烤、炸都要維持整尾，不能切斷。

判定：**部分成立需修正**。除夕有魚、取「餘」的意思，C4 最直接，建議採用。「留一半或留到初一再吃」只見於 C4；「整尾不能切斷」只見於 C7。兩句可以並存（上桌時整尾，吃的時候不吃完），但要分開寫，不能揉成同一條規定。C4 的配方是吳郭魚、魚露，不是站上的清蒸鱸魚，不能把兩份做法拼在一起。C6 的其他吉祥菜（糕、韭菜、丸子）這篇沒有對應菜譜，建議不展開。

### 2-2｜雞：全雞，食雞起家

預計陳述：圍爐的雞用全雞。臺語「雞」和「家」同音，說「食雞，會起家」，起家指成家立業。

- [x] C2 傳藝中心〈只要背好這幾個〉
  - 除夕食物裡的雞一般都用全雞；臺語雞與家諧音，所以說食雞會起家，並把起家解釋為成家立業。
- [x] C3 國家文化記憶庫藏品說明
  - 年夜飯菜色各有含意，全雞有「食雞起家」的好兆頭。
- [ ] C7 移民署〈臺灣過年應景年菜〉
  - 雞的臺語發音像「家」，過年吃雞代表家庭和諧、婚姻美滿。同一段又寫有人相信吃雞腳會「抓」財富、吃雞翅幫助事業「飛」得更高。
- [ ] C10 農業部〈雞肉〉飲食文化
  - 收閩南語諺語「食雞會起家」，用雞與家同音，把養雞、吃雞肉看成家庭圓滿與興旺。這頁的例子是一般節慶與生命禮俗，不是專寫圍爐；同頁還有麻油雞的營養與進補敘述。

判定：**成立，但只採全雞與「起家」**。C7 的雞腳、雞翅是「有人相信」，建議不寫。C10 的諺語沒有綁在除夕，而且同頁有進補說法，建議不收，避免和補冬專題、療效界線攪在一起。滷雞腿不是全雞，不能用來說明這句話。

### 2-3｜長年菜：北部芥菜，南部帶根菠菜

預計陳述：圍爐有一道不切斷的菜，稱長年菜，取長壽。中北部多用芥菜（刈菜），南部多用帶根菠菜，整株川燙、整株吃。

- [x] C5 客家文化發展中心〈長年菜〉
  - 除夕圍爐幾乎家家準備長年菜，取長壽。基隆以南到嘉義，以及宜蘭、花蓮、臺東，用的是芥菜，南北客家人也都以芥菜居多；臺南以南到高雄、屏東，閩南人多用帶根菠菜，整株連根川燙，吃時不切斷。並引《安平線雜記》：隔年菜用菠菜，一根、不折斷，每人吃一根。芥菜帶苦，和油脂一起煮會轉甘，該頁把這說成苦盡甘來。
- [x] C2 傳藝中心〈只要背好這幾個〉
  - 長年菜一般指芥菜，葉片又長又大，象徵長壽；芥菜耐煮，先苦後甘，象徵苦盡甘來。南部大都用菠菜，連根帶葉蒸煮。
- [ ] C6 食農平臺〈長年百歲菜－芥菜〉
  - 把長年菜直接說成芥菜、刈菜：料理時不特別切斷，一根從頭吃到尾。另有一段把客家人稱芥菜為長年菜，解釋成長工在外長年工作、過年才返鄉吃到。

判定：**部分成立需修正**。蔬菜種類與「不切斷」採用 C5：中北部與客家多用芥菜，臺南以南閩南人多用帶根菠菜。C2 的「南部大都菠菜」較粗，不與 C5 的縣市界線對打，正文以 C5 為準。C6 只講芥菜，和 C5 衝突，不拿來當唯一定義。C6 的「長工」由來只有這一頁，沒有另給出處，建議刪。苦盡甘來是 C5、C2 對味道的比喻，可寫成這兩份資料的說法，不寫成食療。站上沒有芥菜或菠菜的長年菜菜譜，正文不連。

### 2-4｜春飯也叫年年有餘，和魚不是同一件事

預計陳述：除夕神桌上有春飯：飯堆高，插春仔花。臺語「春」和「剩」同音，指米飯有剩餘。這和「魚＝餘」是兩套說法。

- [x] C2 傳藝中心〈只要背好這幾個〉
  - 春飯是盛高的白米飯，插紙或布做的春仔花，放在神桌上。臺語「春」與「賰」同音，賰飯就是剩飯，象徵米飯有餘。
- [x] C3 國家文化記憶庫藏品說明
  - 辭年祭品含年粿、春飯；「春」的諧音是「剩」，有年年有餘之意。

判定：**成立**。若正文提到年年有餘，魚和春飯分開寫，避免讀者以為只有魚才表示有餘。春飯不是一道可以連到站上菜譜的菜。

## 篇章 3：家裡怎麼選

### 3-1｜清蒸魚可以連，但不是那份吳郭魚食譜

預計陳述：家裡若要在圍爐上準備一尾魚，可以用站上的清蒸魚。象徵依 C4、C7；做法依既有菜譜，不把水產試驗所的吳郭魚配方寫進來。

- [x] C4 水產試驗所〈年年慶有餘〉
  - 只支持「除夕有魚、取餘、可留到之後或不吃完」，以及「蒸魚」這件事。材料是吳郭魚、魚露、麻油，大火蒸 10 分鐘。
- [x] R1、R2 清蒸魚既有來源
  - 支持站上這道清蒸魚怎麼做。頁面沒有寫年菜或除夕。

判定：**部分成立需修正**。菜譜連結可以留。正文用一句話帶過「整尾蒸魚上桌」，步驟留在菜譜。不寫「傳統清蒸魚就是這份配方」。

### 3-2｜可再熱的是炆、滷，不是「年菜都要前一天做」

預計陳述：久煮的炆菜可以一次做、分幾頓熱來吃。年菜若沒有馬上吃，要盡快冷藏，再熱時中心溫度到 70°C 以上，而且不要反覆熱。

- [x] C8 客家雲〈來吃客家菜來聽客家事〉
  - 四炆是豬肚酸菜湯、客家爌肉、排骨炆菜頭、肥湯炆筍乾。炆指大鍋烹煮、持久保溫。客家名菜多能保存，調理一次可吃好幾頓，方便再次加熱。這是客家宴客菜的特性，不是在寫除夕菜單，也沒有寫「前一天」。
- [x] C9 衛福部〈年菜復熱要當心〉
  - 復熱年菜要到 70°C 以上；避免多次復熱；菜若沒有立刻吃，應儘快冷藏，並寫明「放涼後才能冰」是落伍的觀念。危險溫度帶寫的是 7 到 60°C。

判定：**部分成立需修正**。可以寫「想提前做好的，選可以再熱的炆、滷，並照食藥署的溫度與冷藏方式處理」。不能寫「年菜習俗是前一天先做」，也不能把 C8 的四炆說成就是站上的滷雞腿、台式滷肉或紅酒燉牛肉。C8 同頁有辛香料「醫療功效」、紅麴降血壓等句子，那些不採用。

### 3-3｜這三道菜不寫成年菜

預計陳述（原範圍）：滷雞腿、台式滷肉、紅酒燉牛肉是可以前一天先做的圍爐菜。

- [ ] R3 滷雞腿既有來源
  - 支持這道菜的做法與安全內溫。沒有年菜、全雞或尾牙的記錄。
- [ ] R4 紅酒燉牛肉既有來源
  - 支持這道燉菜的做法。沒有年節記錄。
- 台式滷肉的既有來源同樣只支持家常滷肉做法。

判定：**無依據建議刪除**「這三道是圍爐菜／年菜」。清蒸魚保留。滷雞腿若出現，只能說它是可以再熱的家常滷菜，並明講它不是「食雞起家」的全雞。紅酒燉牛肉建議正文不連。台式滷肉同樣建議不連；客家爌肉才是 C8 點名的炆肉，站上的台式滷肉不是那一道。
