# 08 — 內容與建置輸出檢查指令

Parent: [MVP 實作規格](../../recipe-mvp/issues/09-mvp-implementation-spec.md)

**What to build:** 站主與 CI 執行一個指令，就知道內容能不能發布：它讀取菜譜、內部來源紀錄與建置輸出，回傳通過或逐項列出問題。PR 上任一問題即阻擋合入。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 內部來源紀錄的存放位置建立好：與公開內容分開、位於內容載入範圍與公開資產目錄之外、以菜譜識別值對應、每筆至少一個網址；不被任何頁面或建置產物讀取
- [ ] 來源檢查：每份公開菜譜都有來源紀錄，沒有對不到菜譜的孤兒紀錄（門檻第 2 項）
- [ ] 洩漏檢查：建置輸出不含草稿頁面或 slug，也不含任何內部來源網址（門檻第 3 項）
- [ ] 圖片檢查：料理圖片皆為 WebP、1536×1024、≤ 300 KB、有替代文字；每份公開菜譜有成品圖、材料合照與至少一張步驟圖（門檻第 4 項）
- [ ] 候選池門檻模式：非湯料理配菜候選 ≥ 12、湯 ≥ 3，未達時列出缺額
- [ ] 失敗訊息指出哪份菜譜、哪個欄位或哪個檔案
- [ ] 以小型固定資料為每一種失敗寫單元測試；PR 工作流程對真實內容與建置輸出執行此指令
