# 05 — 首頁即時搜尋

Parent: [MVP 實作規格](../../recipe-mvp/issues/09-mvp-implementation-spec.md)

**What to build:** 讀者在首頁搜尋框輸入菜名、材料、標籤或別名，下方清單立即篩選並顯示符合筆數；字詞寫進網址可分享、可還原；查無結果時看到零筆訊息與清除條件。手機上輸入時大圖收起，結果緊接搜尋框。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 建置後執行 Pagefind；索引只收錄菜譜頁的標題、摘要、材料名稱、受控標籤與別名，分類以篩選屬性提供，標題加權；首頁、關於頁等非菜譜頁與步驟、用量、替代文字不進索引
- [ ] 有字詞時依相關度排序、標題命中優先；無字詞時回到依菜名排序的全部清單；分類篩選在兩種狀態都生效
- [ ] 輸入短暫停頓後即更新；`q` 與分類同步到網址並可還原
- [ ] 零筆時顯示明確訊息與清除條件，不自動放寬
- [ ] 手機搜尋中收起成品大圖
- [ ] Playwright（門檻第 5 項），斷言由內容產生：每道菜譜的菜名、第一項材料與每個別名都查得到它；菜／湯篩選只回該類；只出現在步驟、用量或替代文字的詞查不到；草稿不出現；網址還原；零筆與清除
