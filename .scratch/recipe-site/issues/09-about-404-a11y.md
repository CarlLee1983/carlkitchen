# 09 — 關於頁、404 與無障礙版面門檻

Parent: [MVP 實作規格](../../recipe-mvp/issues/09-mvp-implementation-spec.md)

**Blocked by:** 05, 07

- [x] 在 360、390、430、1366、1920 寬度檢查五個頁面沒有水平捲動
- [x] 分類切換、配菜的鎖定／替換／重抽等觸控目標至少 44×44 px
- [x] 搜尋、分類篩選、配菜的鎖定、替換與重抽都能只用鍵盤完成，焦點可見
