# 03 — 菜譜頁完整版面與圖片管線

Parent: [MVP 實作規格](../../recipe-mvp/issues/09-mvp-implementation-spec.md)

**What to build:** 讀者打開一份菜譜，看到安靜日系版面的完整頁面：菜名、摘要、份數、時間與分類，成品插畫，材料清單與材料合照，編號做法與步驟插畫，每張圖旁的「AI 繪製插畫」，頁底的未試做聲明；可直接列印成一張乾淨的廚房用紙。同時建立全站共用的設計語彙與圖片管線。

**Blocked by:** 02

**Status:** done

- [x] 共用設計語彙：米白底 `#F7F6F3`、炭灰字、細線分隔、明體標題配黑體內文、大量留白；共用頁首（品牌、菜譜、四菜一湯）
- [x] 插畫以帶自身紙底的圖排版，不做去背或混色
- [x] 材料分主料與調味兩組；寬螢幕捲動做法時材料欄保持可見；手機單欄
- [x] 每張料理圖都有替代文字與「AI 繪製插畫」標示
- [x] 頁底聲明「依公開資料由 AI 整理、站主審閱，未經試做」；頁面不出現任何來源連結
- [x] 列印樣式只保留材料、做法與成品圖，隱藏導覽與裝飾
- [x] 圖片以 WebP 母檔（1536×1024）進入內容，頁面經 Astro 圖片元件輸出響應式尺寸
- [x] Playwright：固定資料菜譜頁顯示上述各區塊；列印媒體下導覽隱藏

列印保留小提醒、不印聲明，待站主確認。
