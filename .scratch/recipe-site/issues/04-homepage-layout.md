# 04 — 首頁 I＋J 版面（不含搜尋）

Parent: [MVP 實作規格](../../recipe-mvp/issues/09-mvp-implementation-spec.md)

**What to build:** 讀者打開首頁，第一屏左側是日期、標題、搜尋框與「配一桌四菜一湯」入口，右側是一道隨機已發布菜譜的成品大圖並連到它；下方是全部菜譜清單（縮圖、菜名、摘要、分類），依菜名排序，可切換「全部／非湯料理／湯」，分類寫進網址並可還原。搜尋框此時只是外觀。

**Blocked by:** 03

**Status:** done

- [x] 成品大圖在瀏覽器端每次開啟時從已發布菜譜隨機選出，不以配菜資格限制，點擊進入該菜譜頁
- [x] 清單由建置時的公開菜譜資料產生，依菜名排序，每列有縮圖、菜名、摘要與非湯料理／湯標籤
- [x] 分類切換即時篩選清單並顯示筆數；分類同步到首頁網址，開啟帶參數的網址會還原
- [x] 導覽列「菜譜」連到首頁清單
- [x] 手機版依序為搜尋框、成品大圖、清單
- [x] Playwright：清單依菜名排序、分類篩選與網址還原、大圖連結到存在的菜譜
