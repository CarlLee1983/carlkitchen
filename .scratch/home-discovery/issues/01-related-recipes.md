# 01: 菜譜頁相關菜譜

**What to build:** 每道已發布菜譜頁的最底部（相關食材與專題之後）有「也可以試試」區塊，列出最多 4 道相關菜譜，卡片顯示成品圖與菜名，點下去進到那道菜譜。相關菜譜在建置時依規格的規則算好：同料理主角（主食、湯看類別）優先，再依共用主要材料的稀有度（IDF）加總，同分依「本篇識別值＋候選識別值」的穩定雜湊排序；「調味」「醃料」兩組與香辛料、水排除清單不計分，名稱完全比對。整個區塊不進搜尋索引。這張建立的卡片元件會給首頁隨機推薦共用。規格見 `.scratch/home-discovery/spec.md`〈相關菜譜模組〉。

**Blocked by:** None（可立即開始）

**Status:** ready-for-agent

- [ ] 相似度是純函式：輸入全部已發布菜譜（識別值、類別、料理主角、材料），輸出「識別值 → 依序最多 4 個相關菜譜識別值」；不讀檔、不讀環境變數
- [ ] 排除清單是模組內唯一一處常數，初版內容照規格
- [ ] 單元測試涵蓋：同組優先於跨組、稀有材料勝過常見材料、調味／醃料組與排除清單不計分、完全比對不做同義詞、不含自己、同分時雜湊順序穩定且不同於標題排序、候選不足 4 道、輸出與輸入順序無關
- [ ] 真實資料回歸測試讀正式內容：宮保蝦仁的前幾名包含豆腐蝦仁、蝦仁炒蛋、XO 醬炒雙鮮；橙汁魚片包含杏仁煎魚片、蒜味炸魚片；酒蒸肉丸包含瓜仔肉、洋蔥炒豬絞肉、蒼蠅頭；任何一道的相關菜譜都不含草稿或自己
- [ ] 菜譜頁區塊位於相關食材與專題之後，標題「也可以試試」，整個區塊標上 `data-pagefind-ignore`；沒有任何相關菜譜時不輸出區塊
- [ ] 卡片是可重用元件（成品圖延遲載入、菜名、連結），圖片尺寸與替代文字符合現有圖片 e2e 規則
- [ ] e2e：固定菜譜的菜譜頁有相關菜譜區塊、不含本頁與草稿、連結可點；搜尋某道菜名時，不會因為別頁底部列了這道菜而命中別頁
- [ ] `pnpm check:content` 通過（區塊文案不觸發 AI、試做、餐具等檢查）
- [ ] `pnpm check && pnpm test && pnpm test:e2e` 通過
