# 四菜一湯／五菜一湯的配菜規則

> 歷史規格：分類與配餐標記已由 [ADR 0002](../../../docs/adr/0002-staple-as-category.md) 及 [ADR 0010](../../../docs/adr/0010-browse-kinds-and-meal-roles.md) 更新。兩分類、義大利麵作非湯料理、雙標記皆可無，以及瀏覽與配餐共用標記的描述不再適用；現行規則以 [分類指南](../../../docs/recipe-classification.md)、GLOSSARY 與 schema 為準。本文其餘來源、發布及操作歷史保留。

## Question

用可操作的粗略原型確認四菜一湯／五菜一湯如何從明確標記的候選池抽選、分類、避重、鎖定菜色、單道替換及重新抽選；義大利麵等非湯料理在被標記後如何參與，候選不足、已鎖定菜色與規則衝突、重新整理頁面等邊界情境如何處理？

## Prototype

[配菜規則操作原型](../prototypes/meal-planner-PROTOTYPE.html) 是單檔可雙擊開啟的草稿，包含「一般操作」「替換無解」「鎖定衝突」「候選不足」四個引導情境與自由操作。站主已試用並確認其行為；原型不是正式產品介面。

## Answer

- 站主已試用並認可原型的四個情境。原型是行為證據，不是正式產品介面。
- 每組由四道或五道互不重複的非湯菜色，加一道湯組成；只從已發布且明確標記為配菜候選的菜譜抽選，不限料理地域。每組至少有一道以蔬菜為主角的菜，以及**另一道**蛋白質菜；同一道混合料理即使同時有兩種標記，也不能獨自滿足兩項要求。蛋白質菜可由魚、肉、蛋、豆腐或豆類擔任。
- 候選菜譜可帶「蔬菜菜」「蛋白質菜」兩種受控平衡標記，兩者都可有，也可都沒有。蔬菜只是配料的肉類料理不標成蔬菜菜；站主審稿時確認候選資格與平衡標記。
- 初次抽選和重新抽選都只產生符合規則的組合。重新抽選保留鎖定項，對未鎖定項盡量選擇與上一組不同的菜；候選有限時可保留部分原菜，但同組不得重複。湯也可鎖定與替換。
- 單道替換只改一個未鎖定位置，排除目前已選菜色，並保持菜／湯類別、互不重複與蔬菜／蛋白質平衡。已鎖定項須先解鎖才能替換。找不到替代項時，原套餐不變並說明原因，不暗中放寬規則。
- 四菜／五菜模式切換盡量保留鎖定項，未鎖定位置重新抽選。五菜切四菜若鎖住超過四道非湯菜，保持原模式與套餐並提示先解鎖；其他無解情況同樣保留原狀並說明。候選池不足時不產生不完整或重複套餐。
- 目前套餐、模式與鎖定狀態只在同一瀏覽分頁保留；重整頁面仍在，關閉分頁後可重新開始。若內容更新使已保存的菜譜不再可用，清除失效套餐並要求重新抽選。

實作仍需以正式候選池驗證抽選、鎖定衝突、單道替換無解及重整狀態；原型的示例菜譜不代表正式內容。
