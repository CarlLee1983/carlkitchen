## 產製與驗收

現有 public/prints 是整頁中文加水彩圖的直式 WebP，沒有可重用的產製模板或完整歷史次數紀錄。本批使用正式 imagegen，取番茄炒蛋分享圖作排版參考、各道既有 hero 作料理參考。中文全文從各 recipe.yaml 提取，沒有補用量或刪略步驟。

每張 historicalAttempts 為 unknown，本輪各 1 次，無追加生成、沒有重置歷史。正文 skill 的 1536×1024 橫圖轉檔不適用分享圖；本批沿用既有 864×1152 直式，使用原生 cwebp 1.6.0 q80 等比縮小，沒有裁切，再用 dwebp 完整解碼。4 張均低於 300 KiB（95,714–108,098 bytes）。原 PNG 不入 repository。

逐張查看原圖與輸出 WebP，另作獨立逐字核對：標題、摘要、份量／時間、材料與用量／單位、所有步驟、小提醒均一致。檢查完整邊緣，文字和容器無裁切。324px 縮圖可辨識菜名與料理，完整內文需開原圖放大閱讀；不冒稱縮圖等同正常正文閱讀尺寸。

現有列印 CSS 依可列印寬度與 3:4 原圖縮放，因此本批與既有比例相同，無需改 UI。瀏覽器 PDF 單頁與 Web Share 流程沿用既有 E2E；本地 Chromium ZIP 損壞、替代 Chromium socket EPERM 為已確認限制，本批未重試下載或繞過 sandbox。完整瀏覽器 E2E 以此 PR exact-head CI 補驗；iOS／Android 原生列印選單未實機驗證。
