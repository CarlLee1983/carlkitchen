## 篇章 1：小吃是什麼

### 1-1｜「小吃」「點心」指正餐以外的食物

- [x] 教育部《臺灣台語常用詞辭典》「點心」 https://sutian.moe.edu.tw/zh-hant/su/12455/
  - 台語「點心」指有別於正餐的食物，舉糕餅和小吃為例；反義詞是「正頓」（正餐）。
- [x] 教育部《臺灣台語常用詞辭典》「夜市」 https://sutian.moe.edu.tw/zh-hant/su/3773/
  - 夜市是夜間營業的市場，通常由賣小吃或日用品的攤位聚集而成。（同時支撐 1-2）

判定：**成立**。可以寫：小吃在台語常歸在「點心」，相對於正餐。辭典沒有替「小吃」本身下定義，不要寫成「小吃的定義是……」，改寫成「台語把正餐以外的食物叫點心，小吃也算在裡面」。

### 1-2｜夜市與小吃攤的關係

- 教育部「夜市」詞條（同 1-1）。
- [x] 交通部觀光署〈夜市之旅〉 https://www.taiwan.net.tw/m1.aspx?sNo=0001040
  - 觀光署把小吃寫成臺灣具代表性的飲食文化，列舉的小吃含炒米粉、臺南擔仔麵、滷肉飯等；說夜市集中大量小吃、各夜市有自己的特色，羅東夜市的介紹列了肉羹。頁面語氣是觀光宣傳（「獨步全球」等），只取事實不取形容。
- [x] 交通部觀光署〈六合觀光夜市〉 https://www.taiwan.net.tw/m1.aspx?id=2245&sno=0001016
  - 高雄六合夜市的前身：1950 年起大港埔空地聚集小吃攤，逐漸形成夜市。只能寫成「以高雄六合夜市為例」，不能推成全臺夜市都這樣形成。

判定：**成立**。夜市是小吃攤集中的地方，有辭典與觀光署支撐；六合夜市的年份只能當單一例子。

### 1-3｜「擔仔」與「擔仔麵」的名稱

- [x] 教育部《臺灣台語常用詞辭典》「擔仔」 https://sutian.moe.edu.tw/zh-hant/su/13826/
  - 「擔仔」就是攤子、攤販；用例有「麵擔仔」（麵攤）和「在路邊擺攤」。
- [x] 教育部《臺灣台語常用詞辭典》「擔仔麵」 https://sutian.moe.edu.tw/zh-hant/su/11659/
  - 辭典記為臺南小吃：油麵加上少量用沙鍋燉的肉燥；名稱來自早期用擔子挑著沿街賣。（同時支撐 2-2、3-2）
- [x] 國立臺灣歷史博物館「臺南文史研究資料庫」：連景初〈擔仔麵史話〉，《臺南文化》第 9 卷第 1 期（1969） https://tainanstudy.nmth.gov.tw/article/detail/686/read
  - 全文逐字稿可讀。文章以「據說」轉述度小月的掌故：清末撐船的洪芋頭在淡季挑麵擔到水仙宮前擺攤，擔上掛「度小月」燈籠；客人蹲在擔旁吃麵。作者寫作當時說已傳承七十年以上。

判定：**成立（措辭修正）**。「擔仔」＝攤子、擔仔麵因挑擔沿街賣得名，有辭典支撐。度小月的掌故只能寫成「1969 年《臺南文化》記載的傳說」，不寫成確定史實，也不寫「擔仔麵起源於某年」。

### 1-4｜小吃的起源年代、「全臺夜市都這樣」

- 沒有候選。

判定：**無依據建議刪除**。所有來源都只記錄個別地方或個別店家（臺南度小月、高雄六合夜市），沒有任何來源給出「小吃」或「夜市文化」的整體起源年代，也沒有來源支持「全臺都這樣」。

## 篇章 2：幾類小吃各自的特色

### 2-1｜炒米粉

- [x] 教育部《臺灣台語常用詞辭典》「米粉炒」 https://sutian.moe.edu.tw/zh-hant/su/2708/
  - 台語叫「米粉炒」，近義詞是「炒米粉」；辭典稱它是有名的臺式料理，做法是米粉和食材、調味料一起用油炒熟。
- [x] 國家文化記憶庫〈新竹米粉發展的歷史探由〉（新竹市文化局建檔，原刊《竹塹文獻雜誌》第 11 期，1999） https://tcmb.culture.tw/zh-tw/detail?indexCode=Culture_Object&id=147076
  - 新竹米粉的業者祖先多來自福建惠安；新竹風強雨少，利於風乾米粉；日治中期以前以粗條水粉為主，細絲炊粉約 1920 年才引進。談的是米粉這項食材的產地與製法，不是炒米粉這道菜。
- 交通部觀光署〈夜市之旅〉（同 1-2）把炒米粉列在臺灣小吃之中。

判定：**部分成立需修正**。炒米粉是用油把米粉和料一起炒熟、被當作小吃列舉，可以寫。新竹的資料只能拿來介紹「米粉」這個食材，不能寫成「炒米粉源自新竹」。辭典稱「臺式料理」、觀光署稱「小吃」，兩種說法並存，文章不必擇一。

### 2-2｜肉燥與肉燥麵

- [x] 教育部《臺灣台語常用詞辭典》「肉燥」 https://sutian.moe.edu.tw/zh-hant/su/28534/
  - 肉燥是五花肉絞碎後和蔥、香菇等一起炒，再加醬油熬煮，多半用來拌麵或拌飯。
- [x] 教育部《臺灣台語常用詞辭典》「肉燥飯」 https://sutian.moe.edu.tw/zh-hant/su/28609/
  - 辭典記錄：同樣是肉燥淋飯，臺灣南部叫「肉燥飯」，中北部慣稱「滷肉飯」。
- 教育部「擔仔麵」（同 1-3）：擔仔麵的特色就是少量肉燥加在油麵上。
- [x] 國立臺灣歷史博物館「臺南文史研究資料庫」：臺島生〈担仔麵〉，《臺南文化》第 2 卷第 4 期（1953） https://tainanstudy.nmth.gov.tw/article/detail/110/read
  - 全文逐字稿可讀。描寫當時度小月的吃法：一大把切麵配豆芽或萵菜，在湯鍋裡燙到剛熟就撈起，澆上清湯、肉臊和蔥頭油。（同時支撐 3-1）

判定：**成立（範圍提醒）**。肉燥的材料、熬法和拌麵飯的用途有辭典依據。站上肉燥麵用的是絞肉而非五花肉、配意麵而非油麵，文章要說清楚是「菜譜的做法」，不要說成「傳統肉燥就是這樣」。南北「肉燥飯／滷肉飯」的名稱差異可以一句帶過；選題清單另有〈滷肉飯與肉燥〉候選，若兩篇都做，這段留給那篇細談。

### 2-3｜肉羹

- [x] 教育部《臺灣台語常用詞辭典》「肉羹」 https://sutian.moe.edu.tw/zh-hant/su/2818/
  - 肉羹有兩個意思：一是把肉搥成漿抓成條，或在肉片外裹肉漿、芡粉後煮熟的食品；二是用這種肉漿條或肉漿片調味煮成的湯。
- [x] 教育部《臺灣台語常用詞辭典》「魚漿」 https://sutian.moe.edu.tw/zh-hant/su/27529/
  - 魚漿是低脂魚肉絞碎後持續低溫攪拌成的稠漿，辭典舉肉羹、魚丸、花枝丸等加工食品為用途。（同時支撐 3-4）
- [x] 國家文化記憶庫〈北港肉羹〉（新北市政府文化局建檔，2017 年攝） https://tcmb.culture.tw/zh-tw/detail?indexCode=Culture_Place&id=194604
  - 新北南雅夜市門口的肉羹攤，以老家地名當店名；撰寫者認為夜市攤常把家鄉掛在招牌上，可以看出移民帶來家鄉口味。這是撰寫者對單一夜市的觀察。
- [x] 國家文化記憶庫〈原岡山眷村欣欣菜場商販欣欣鴨肉羹〉（高雄市岡山眷村文化協會建檔） https://tcmb.culture.tw/zh-tw/detail?indexCode=Culture_Place&id=571935
  - 岡山欣欣菜場的鴨肉羹攤，第一代老闆挑擔到市場邊賣，經營六十多年，2019 年市場拆除時結束。

判定：**成立**。肉羹是裹肉漿或芡粉的肉，再煮成湯，有辭典依據。兩則記憶庫資料可擇一當攤子的實例（挑擔賣羹、夜市攤以家鄉為招牌），只能寫成個案，不推論成普遍現象。

### 2-4｜鹽酥雞（鹹酥雞）

- [x] 教育部《臺灣台語常用詞辭典》「鹹酥雞」 https://sutian.moe.edu.tw/zh-hant/su/13069/
  - 辭典記為一種小吃：雞胸肉切小塊，用醬油、糖、酒、五香粉等醃，再裹麵粉或番薯粉炸到金黃後販售。華語用「鹽酥雞」查得到這一條。
- [x] 農業部桃園區農業改良場〈料理的靈魂配角，帶你認識「九層塔」的秘密〉 https://www.tydares.gov.tw/ws.php?id=11007&print=Y
  - 資訊圖卡：臺灣九層塔分紅骨、青骨兩類；青骨味道較清，常用在湯品和鹹酥雞。另提到九層塔不耐貯藏、怎麼保存。
- [ ] 國立教育廣播電臺〈台灣鹽酥雞 Taiwanese Fried Chicken〉（《環球美食家》，2025-11-03 首播節目摘要） https://channelplus.ner.gov.tw/episode/03e30e36-d108-4191-95e5-597b32e77828
  - 節目摘要列出兩種起源說法（1975 年臺北西門町、1979 年臺南），並說真相不確定。這是英語教學節目的文字摘要，不是史料。

判定：**部分成立需修正**。做法（小塊雞胸肉醃過、裹粉油炸）與九層塔搭配有依據，辭典和菜譜的醃料也一致。**起源不寫**：唯一提到起源的教育電臺節目自己列出兩種互相衝突的說法，不能挑一個寫成事實。若站主想提，只能寫「起源有不同說法」，那就需要勾這個來源；不提就不必勾。

### 2-5｜蚵仔類小吃與蒜泥蚵仔

- [x] 交通部觀光署〈飲食特色〉 https://www.taiwan.net.tw/m1.aspx?sNo=0020553
  - 「海鮮豐富」段：牡蠣又叫蚵仔，在臺灣主要產在西南沿海與澎湖。頁面後段有「節令食補」與藥膳功效的寫法，**只取牡蠣產地這一句，不引用功效段**。
- [x] 教育部《臺灣台語常用詞辭典》「蚵仔麵線」 https://sutian.moe.edu.tw/zh-hant/su/7823/
  - 地方小吃：蒸過的紅麵線煮成糊，加入裹粉後稍微煮過的蚵仔，有時加大腸。
- [x] 教育部《臺灣台語常用詞辭典》「蚵仔煎」 https://sutian.moe.edu.tw/zh-hant/su/7822/
  - 臺灣著名小吃：鮮蚵加地瓜粉和水調成糊，和青菜、蛋一起在平底鍋油煎。

判定：**部分成立需修正**。**找不到任何公部門或出版社來源記錄「蒜泥蚵仔」本身的文化背景**（辭典、觀光署、記憶庫都沒有這道菜）。可以寫的是：蚵仔是臺灣西南沿海與澎湖的產物，蚵仔麵線、蚵仔煎這些小吃都會先讓蚵仔沾地瓜粉；蒜泥蚵仔的菜譜同樣先裹地瓜粉再下水煮。不能寫「蒜泥蚵仔是夜市常見小吃」或任何蒜泥蚵仔的起源；選題清單把它放在〈熱炒店下酒菜〉候選裡，站主可考慮在本篇把它定位成「和蚵仔小吃同樣裹粉的家常做法」，或換成其他有文化記錄的小吃。

### 2-6｜擔仔麵與摵仔麵的分別

- 教育部「擔仔麵」（同 1-3）。
- [x] 教育部《臺灣台語常用詞辭典》「摵仔麵」 https://sutian.moe.edu.tw/zh-hant/su/10541/
  - 摵仔麵是用竹籠狀的撈麵器具把麵放進熱湯裡上下抖動煮熟，再加湯頭和配料；辭典把它和擔仔麵列為近義詞。（同時支撐 3-1）

判定：**成立**。這條可放在肉燥麵段落，說明「麵攤的麵怎麼煮」，不需另寫一節。

## 篇章 3：攤子與家裡的差別

這段最容易寫成推論。下面每條都標明來源實際說了什麼，沒有來源的說法列在 3-5 建議整段刪除。

### 3-1｜麵攤用一鍋熱湯燙麵，起鍋後再淋湯和肉燥

- 臺島生〈担仔麵〉（1953，同 2-2）：麵和豆芽放在湯鍋燙到剛熟就撈，澆清湯、肉臊、蔥頭油。
- 教育部「摵仔麵」（同 2-6）：用撈麵器具在熱湯裡抖動煮麵。
- [x] 楊桃美食網「肉燥麵」（**已是菜譜核准來源**） https://www.ytower.com.tw/recipe/iframe-recipe.asp?seq=A02-1325
  - 以 Big5 腳本抓取並轉碼確認。家庭版分兩鍋：先在炒鍋爆香紅蔥蒜、炒絞肉，加調味和 100 ml 高湯小火煮到收汁；另起一鍋水煮麵，撈起後淋上肉燥。材料：絞肉 130 g、意麵 170 g。

判定：**部分成立需修正**。可以寫：歷史記錄裡的擔仔麵攤是在湯鍋燙麵、起鍋淋湯與肉燥；摵仔麵用撈麵器具在熱湯裡煮；站上菜譜改成一鍋煮肉燥、一鍋水煮麵。只能寫到「做法不同」，不能寫「攤子的湯整天熬、所以比較香」或「攤子高湯鍋比較大」，來源沒有說。

### 3-2｜肉燥事先燉好、等客人點了再淋

- 教育部「擔仔麵」（同 1-3）：擔仔麵用的是沙鍋燉出的肉燥。
- 臺島生〈担仔麵〉（同 2-2）：店裡攤上另外陳列滷味；麵和豆芽是店家自己醃製。
- 楊桃美食網「肉燥麵」（同 3-1）：家庭版肉燥炒好後小火煮到略收汁，當餐吃完。

判定：**部分成立需修正**。「擔仔麵的肉燥用沙鍋燉」有辭典支撐；「攤子先燉好一大鍋、整天取用」只是合理推測，來源沒寫，建議改成「辭典記載擔仔麵的肉燥是用沙鍋燉的；家裡的菜譜則是炒過後加高湯小火收汁，一次做兩人份」。搜尋摘要中出現的「肉燥鍋數十年不洗」來自觀光網店家介紹，屬店家宣傳，未列候選，不要寫。

### 3-3｜攤販的油炸用油

- [x] 衛生福利部〈衛生單位持續把關油炸油衛生安全〉（2013-06-19） https://www.mohw.gov.tw/cp-3213-23273-1.html
  - 食藥局（現食藥署）說明，油炸油稽查的對象涵蓋夜市攤販、路邊攤、小吃店等 10 種餐飲業態；先驗酸價，超過 2.0 再驗總極性化合物，101 年全國稽查一萬三千多件油品。
- [x] 衛生福利部〈衛生署呼籲餐飲業者正確使用油炸油〉（2009-06-22） https://www.mohw.gov.tw/cp-3162-27509-1.html
  - 針對長時間油炸的餐飲業者：要選穩定度高的油、隨時撈渣過濾；發煙點低於 170°C、油色深黏且泡沫超過鍋面一半、酸價超過 2.5、極性物質達 25% 以上，任一種就要整鍋換新。
- [x] 楊桃美食網「鹽酥雞(1)」（**已是菜譜核准來源**） https://www.ytower.com.tw/recipe/iframe-recipe.asp?seq=A03-341
  - 以 Big5 腳本抓取並轉碼確認。家庭版：半塊雞胸肉切拇指大小，醃汁用果汁機打 30 秒，醃 30 分鐘，裹地瓜粉後過粗孔篩，油溫 150°C 炸約 2 分鐘，最後放九層塔約 2 秒一起撈起。來源沒有寫油量。

判定：**部分成立需修正**。可以寫：夜市攤販與路邊攤的油炸油屬衛生機關稽查項目，營業用油要依劣化指標換油；家裡照菜譜一次炸兩人份。**不能寫**「攤販用一大鍋油」「攤販油溫比家裡高」「家裡油量不夠所以不脆」，來源都沒有。這兩篇衛福部新聞是 2009、2013 年的舊聞，寫的時候要標年份，不要寫成現行數據；「發煙點低於 170°C 就換油」是給業者的判斷標準，不要轉成家庭的建議。

### 3-4｜攤子自己打肉漿，家裡用買來的肉羹

- 教育部「肉羹」「魚漿」（同 2-3）：肉羹是用肉漿做的；魚漿是加工食品原料，肉羹是其用途之一。
- [x] 楊桃美食網「肉羹湯(2)」（**已是菜譜核准來源**） https://www.ytower.com.tw/recipe/iframe-recipe.asp?seq=A02-3457
  - 以 Big5 腳本抓取並轉碼確認。材料直接用現成「肉羹」300 g；湯底用電鍋：雞骨加 1000 ml 水，外鍋 1 杯水煮到跳起再燜 5 分鐘，泡柴魚片 1 分鐘後撈除，加香菇、紅蘿蔔、筍絲，外鍋再 1 杯水煮 15 分鐘，下肉羹煮到跳起，勾芡調味。

判定：**部分成立需修正**。可以寫：肉羹本身是先用肉漿做好的食品，站上的菜譜直接用現成肉羹、用電鍋煮湯底。**不能寫**「攤子都自己打肉漿」，辭典只說明肉羹是什麼，沒有說誰做；記憶庫兩則肉羹攤資料也沒提。

### 3-5｜火力、鍋具大小、預先備料的一般性比較

- 沒有候選。

判定：**無依據建議刪除**。以下說法沒有找到任何來源支持，建議不寫：
- 攤販或熱炒爐火力比家用瓦斯爐大，所以炒米粉、鹽酥雞在家做不出攤子的口感。
- 攤販的高湯鍋整天熬、湯頭比家裡濃。
- 攤販油鍋油量大、油溫穩定，家裡油量少容易掉溫。
- 小吃攤普遍「預先備料、現點現組合」（只有擔仔麵的歷史記錄可以當個案，見 3-1、3-2）。

### 3-6｜家裡做的器材與時間

- 五道菜譜的核准來源（見篇章 4）都寫了器材與步驟時間，這一條能完全靠菜譜回答。

判定：**成立**。篇章 3 可以改成「家裡的做法」而非「攤子為什麼比較好吃」：從菜譜看得到家庭版的器材（炒鍋、電鍋、果汁機、湯鍋）、溫度與時間，以及肉羹用現成品、肉燥一次做小份這些具體差別。建議篇章標題也跟著改，避免讀者期待一篇攤販設備的比較。

### 4-1｜五道菜的來源

- [x] 楊桃美食網「台式炒米粉(2)」（**已是菜譜核准來源**） https://www.ytower.com.tw/recipe/iframe-recipe.asp?seq=A02-2789
  - 以 Big5 腳本抓取並轉碼確認。乾米粉 200 g 先滾水燙約 1 分鐘、撈起加蓋燜 10 分鐘；炒鍋爆香紅蔥、香菇、蝦米、肉絲，加高麗菜、紅蘿蔔，倒 120 ml 高湯煮滾，下米粉和調味小火拌炒，最後加芹菜、香油。
- 楊桃美食網「肉燥麵」（同 3-1）。
- 楊桃美食網「肉羹湯(2)」（同 3-4）。
- 楊桃美食網「鹽酥雞(1)」（同 3-3）。
